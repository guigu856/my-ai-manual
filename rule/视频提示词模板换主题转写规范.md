# 视频提示词模板换主题转写规范

> 适用于基于既有视频生成提示词模板，将其转写为其他主题，同时保留原模板结构能力、画面等级、分镜粒度和节奏组织方式的任务。

---

## 1. 核心原则：保留骨架，不复制内容

模板换主题不是在原提示词上做轻微替词，也不是脱离模板重新写一份新提示词。

必须同时满足两组要求：

- **骨架高保真**：保留原模板的结构逻辑、画面风格等级、分镜描述粒度、分镜时间粒度、节奏组织方式、提示词写法密度、转场因果和约束强度。
- **内容可发散**：人物设定、元素系统、意象系统、主题表达、叙事机制和局部场景可以明显重构，不被原模板的具体物件和母题绑定。

判断标准：删除主题名后，两版提示词应能看出属于同一种“生成规格”；只看人物、意象和故事时，又应当明显是不同主题作品。

## 2. 模板内容分层

转写前先将原提示词内容按职责分为四层。

### 2.1 骨架契约层

默认保留，不随主题变化：

- 文档章节结构与信息顺序。
- 整体时长和分段方式。
- 单个时间段的描述密度。
- “第一拍、第二拍、第三拍”等节拍组织方式。
- 每拍只保留一个主要视觉锚点等画面控制规则。
- 转场必须由前一镜头元素自然匹配变形成后一镜头主体的因果要求。
- 高潮、停顿、静止、爆发、重新排版等节奏层级。
- 严格限制的约束强度和检查粒度。

### 2.2 可复用风格层

与目标主题不冲突时直接保留，只在必要处调整：

- 二维 / 三维、写实 / 非写实等基础媒介约束。
- Editorial MG、赛璐璐、杂志排版、平面设计等整体美术体系。
- 色彩结构、正负形、留白、排版密度、图层关系。
- 镜头运动语言和禁止的普通电影式运镜。
- 印刷、纸张、版式、线条、几何切片等通用视觉语言。
- 角色一致性、风格稳定性、禁止畸形等生成约束。

不要为了“看起来变化很大”而主动重写仍然适用的风格描述。

### 2.3 主题耦合层

必须根据新主题重构：

- 核心视觉母题。
- 人物身份、关系、行为逻辑。
- 主题象征物。
- 情绪机制。
- 叙事冲突。
- 关键动作。
- 高潮表达。
- 结尾落点。

主题耦合层不能只做同义替换，必须让新元素真正承担新主题的叙事功能。

### 2.4 具体内容层

可以保留、替换或删除，以是否仍服务新主题为唯一判断标准：

- 刀、月相、蝴蝶、酒杯、沙发、城市、怪物等具体物件。
- 某个角色的发型、武器、服装和职业身份。
- 某种固定场景。
- 某个标题或 Logo 拼装方式。

原模板出现过的元素不自动获得保留优先级。

## 3. 主题转写：先重建表达机制

新主题不能只停留在关键词层面，必须先建立“主题如何被画面看见”的表达机制。

至少明确：

- 主题核心冲突是什么。
- 观众应该感受到什么。
- 哪些视觉现象能直接表达该冲突。
- 哪些动作、构图或状态变化可以反复承担主题叙事。
- 哪些元素只负责装饰，哪些元素负责推进故事。

例如，用户要求“更疯感 / 更危险 / 更艺术化”时，不能只增加这些形容词。必须把它们落到可生成的视觉行为中，例如：

- 人物与镜像动作不同步。
- 同一张脸在不同版面中出现互相矛盾的表情。
- 页面争夺主体位置。
- 画面突然压缩到极窄视觉区域。
- 危险色只在明确接管节点出现。
- 角色保持静止，但其影子、镜像或版面版本继续行动。

情绪修饰词必须转译成动作、构图、色彩、节奏或转场规则。

## 4. 元素系统：围绕主题重新设计

新主题应建立自己的元素系统，不得默认沿用原模板的核心物件。

元素设计必须满足：

- 与主题直接相关。
- 能在多个镜头中重复出现。
- 能承担转场。
- 能在不同尺度下保持识别性。
- 能从具象物变成几何结构，再变成下一镜头主体。
- 数量受控，不形成无序堆叠。

优先设计一组可以互相转化的核心母题，例如：

```text
元素 A
→ 几何化
→ 元素 B
→ 页面结构
→ 元素 C
→ 高潮主体
```

不能只列一组“好看的元素”，必须明确它们之间的变形关系。

## 5. 人物设定：随主题改变行为逻辑

人物不能只换服装、发色或武器。

需要重写：

- 人物在主题中的身份。
- 人物与冲突的关系。
- 人物最具识别度的动作。
- 人物情绪如何通过姿态、眼神、停顿、手指、身体重心等表现。
- 人物与核心视觉母题如何发生关系。

如果原模板依靠“持刀、拔刀、挥刀”制造角色魅力，而新主题与武器无关，就应替换为新的行为机制，不强行保留武器动作。

角色外形和动作可以变化，但原模板的人物表现粒度、镜头优先级和一致性约束应继续保留。

## 6. 分镜转写：保留粒度，重写内容

### 6.1 时间粒度

原模板如何拆时间，新版本原则上继续沿用。

例如原模板使用：

```text
0–3 秒
3–6 秒
6–9 秒
9–12 秒
12–15 秒
```

则新主题继续使用同级时间颗粒，除非用户明确要求改变总时长或节奏结构。

### 6.2 描述粒度

原模板每个时间段包含几拍、每拍描述多少动作、转场写到什么程度，新版本必须维持相近密度。

不能出现：

- 原模板每 3 秒描述 4 个清晰节拍，新版本只写一句概述。
- 原模板详细描述视觉锚点、运动顺序和转场，新版本只写“画面切换到下一个场景”。
- 原模板明确每层元素错峰出现，新版本把所有元素合并成“同时爆发”。

### 6.3 节奏骨架

保留原模板的节奏功能，而不是复制原动作。

例如：

```text
留白建立
→ 主体第一次异常
→ 视觉系统展开
→ 稳定推进
→ 局部失控
→ 高潮
→ 绝对静止
→ 结尾锚点
```

动作内容可以完全变化，但节奏层级不能被抹平。

## 7. 转场规则：必须存在图形因果

每一次主要转场都要回答：

> 前一个镜头中的哪个可见结构，变成了下一个镜头中的什么？

允许使用：

- 轮廓匹配。
- 正负形替换。
- 色块扩张或收缩。
- 裁切线变成场景结构。
- 眼睛 / 圆点 / 缺口变成新的主体。
- 页面翻折变成空间边界。
- 镜面、面具、纸片、阴影等二维结构翻面重组。

禁止：

- 无因果硬切后用一句“自然转场”带过。
- 普通淡入淡出代替设计。
- 为炫技加入与叙事无关的随机变形。
- 前一镜头元素消失后凭空生成下一主体。

转场本身也是主题表达的一部分。

## 8. 原文保留规则

“原提示词内容能保留的保留，需调整的调整”按以下标准执行：

### 直接保留

- 对新主题仍完全成立的风格约束。
- 对新主题仍完全成立的生成限制。
- 与主题无关的质量控制规则。
- 原模板的分镜组织句式和信息密度。

### 局部改写

- 风格规则中绑定旧元素名称的部分。
- 转场规则中列举旧母题的部分。
- 角色一致性规则中绑定旧角色道具的部分。
- 颜色规则中与新主题冲突的强调色用途。

### 完整重写

- 旧主题人物设定。
- 旧主题核心意象。
- 旧主题叙事冲突。
- 旧主题高潮事件。
- 与旧故事强绑定的具体镜头。

禁止为了“不是小修小改”而把全部内容重新措辞，也禁止为了“保留原版”而强行保留不再服务主题的旧元素。

## 9. 严格限制必须同步更新

新提示词完成后，严格限制不能原样复制。

必须检查：

- 是否仍禁止新版本已经需要的内容。
- 是否仍要求旧版本已经不存在的道具或角色。
- 是否遗漏新主题最容易生成错误的风险。
- 是否对人物一致性、元素数量、风格漂移、转场方式继续有明确约束。

新主题产生的新风险要加入限制。

例如：

- 多重人格主题需要限制模型把同一角色生成成多个不同人物。
- 镜像主题需要限制镜像脸型、服装、五官和肢体漂移。
- 面具或切片设计需要说明其为二维版面元素，避免生成真实身体破坏。

限制项必须与正文中的设计一一对应。

## 10. 最终输出：必须是可直接使用的提示词

最终交付只写成品提示词，不写转写过程。

禁止出现：

- “主题改为……”
- “这里沿用原版……”
- “这一段相比原版……”
- “为了体现新主题……”
- “原模板中的 X 被替换为 Y……”
- “根据你的要求……”
- 修改说明、差异说明、设计推导、方案比较、对话痕迹。

最终文本应当像这份提示词从一开始就是为当前主题独立设计的。

## 11. 文档结构

默认沿用源模板的章节结构，不额外创造与生成无关的说明章节。

当源模板包含以下结构时，继续使用：

```text
# [主题 / 项目名称]

## 第一段 · [时间]

整体描述

### 美术风格

### 角色

### 分镜

#### [时间段]
第一拍｜...
第二拍｜...
第三拍｜...

### 严格限制

## 第二段 · [时间]
...
```

如果源模板没有第二段、角色章节或标题落版，则不强制新增。

## 12. 转写执行流程

按以下顺序执行：

1. 读取完整源提示词。
2. 提取骨架契约层、可复用风格层、主题耦合层、具体内容层。
3. 冻结结构逻辑、画面风格等级、分镜描述粒度、分镜粒度、节奏组织方式和写法密度。
4. 明确新主题的核心冲突和目标情绪。
5. 设计新的角色机制、元素系统、意象系统和元素变形链。
6. 按原时间粒度逐段重写分镜。
7. 检查每次主要转场的图形因果。
8. 重写与新主题相关的严格限制。
9. 删除所有过程说明和模板对比痕迹。
10. 输出完整、连续、可直接用于生成视频的最终提示词。

## 13. 失败模式

### 13.1 只换名词

错误：

```text
月相 → 面具
蝴蝶 → 镜子
大太刀 → 手镜
```

如果镜头动作、叙事关系和转场逻辑完全不变，只是物件换名，不算完成主题转写。

### 13.2 被原元素绑死

错误：新主题与刀、月相、蝴蝶无关，仍为了“像模板”强行让这些元素继续出现。

保留的是模板能力，不是模板道具库存。

### 13.3 全部推翻

错误：新版本重新设计了结构、分镜颗粒、节奏、运镜和写法密度，最终只剩相似画风。

这属于重新创作，不属于模板转写。

### 13.4 只有形容词变化

错误：增加“疯狂、危险、高级、艺术化”等词，但画面行为没有变化。

情绪必须转成可观察的视觉机制。

### 13.5 分镜降级

错误：源模板具有高密度逐拍描述，新版本退化成概述式脚本。

模板的描述粒度属于必须保留的骨架。

### 13.6 过程文字进入成品

错误：最终提示词中仍出现“保留原版”“改成新主题”“这一版调整为”等过程说明。

最终交付必须只描述当前成品。

## 14. 执行检查

交付前逐项检查：

- [ ] 结构逻辑与源模板同级。
- [ ] 画面风格等级没有下降。
- [ ] 分镜时间粒度与源模板一致或有明确任务要求支撑变化。
- [ ] 每段描述密度与源模板相近。
- [ ] 节奏仍存在留白、推进、爆发、静止和高潮层级。
- [ ] 新人物行为直接服务新主题。
- [ ] 新元素系统不依赖原模板具体物件。
- [ ] 核心元素之间存在可执行的变形链。
- [ ] 每次主要转场都有前后图形因果。
- [ ] 情绪要求已经转成具体动作、构图、色彩或节奏规则。
- [ ] 仍适用的原风格和质量限制没有被无意义重写。
- [ ] 已删除与旧主题强绑定且不再适用的内容。
- [ ] 严格限制已同步新主题风险。
- [ ] 最终文本没有修改说明、对比说明和对话痕迹。
- [ ] 最终文本可以直接复制给视频生成模型使用。

检验标准：把新提示词单独交给一个不了解原模板的人阅读，它应当是一份完整、独立、可执行的当前主题生成提示词；把它与源模板并排比较，又能清楚看到两者共享同一套结构与生成方法。
