# 提示词模板主题转写规则

> 用于将一份已有的图像、视频或视觉创作提示词模板转写为新的主题版本。
>
> 输出文档同时遵循 [`文档编写规范.md`](./文档编写规范.md)：只保留最终规则与最终提示词，不保留推导过程、版本历史和对话痕迹。

---

## 1. 转写目标

主题转写不是对原提示词做逐项替换，也不是尽量保留原主题表面元素。

转写的目标是：

- 保留原模板中真正决定成片质量的**结构骨架与表达方法**。
- 保留原模板的**画面等级、镜头描述精度、节奏组织和提示词密度**。
- 根据目标主题重新设计**人物、元素、场景、意象、配色、主题表达与视觉冲突**。
- 让新提示词具备独立完整的视觉世界，不依赖读者知道原模板内容。
- 最终产物必须可以直接复制给生成模型使用。

---

## 2. 输入与输出

### 2.1 输入

至少需要：

- 原始提示词模板。
- 目标主题。

可选输入：

- 情绪要求，例如：疯感、危险、华丽、压迫、梦幻、诡异、神圣、躁动。
- 强度要求，例如：更克制、更炸裂、更混乱、更艺术化。
- 人物参考图、服装参考图、构图参考图或色彩参考图。
- 目标时长、镜头数量、画幅、平台或生成模型限制。
- 必须保留或禁止出现的元素。

### 2.2 输出

输出为一份完整的新主题生成提示词。

最终提示词中不得出现：

- “根据原版修改”。
- “主题改为……”。
- “相比原版……”。
- “保留了原模板……”。
- “这一版……”。
- 修改说明、设计解释、版本比较、方案选择记录。

---

## 3. 核心原则：迁移方法，不复制表面

原模板拆分为三层：

| 层级 | 处理方式 | 内容 |
| :-- | :-- | :-- |
| 骨架层 | 强制继承 | 结构逻辑、章节组织、镜头描述粒度、节奏组织方式、提示词密度、转场设计方法、画面完成度等级 |
| 机制层 | 按功能继承 | 视觉锚点控制、信息密度控制、爆发与停顿关系、图形匹配、角色一致性、视觉因果、高潮构建方式 |
| 表面层 | 为目标主题重构 | 人物身份、性别、服装、道具、场景、核心母题、色彩、符号、意象、标题、世界观、具体动作 |

主题转写的判断标准不是“新提示词和原提示词长得像不像”，而是“新提示词是否使用了同等级的创作方法完成新的主题表达”。

---

## 4. 必须继承的内容

除非用户明确要求改变，以下内容优先保持与原模板同等级：

### 4.1 结构逻辑

保持原模板的信息组织方式，例如：

- 整体定位。
- 美术风格。
- 角色设计。
- 分镜。
- 严格限制。
- 多段视频之间的承接关系。

原模板存在第一段、第二段或多个章节时，新版本保持同等层级的组织方式。

### 4.2 分镜粒度

保持原模板对时间和动作的拆分精度。

原模板按 `0–3 秒 / 3–6 秒 / 6–9 秒` 描述时，新版本不得退化成：

- “开场出现人物”。
- “中间发生冲突”。
- “结尾出现标题”。

原模板细化到“第一拍、第二拍、局部动作、锚点变化、转场结果”时，新版本保持同等级描述。

### 4.3 提示词密度

保持原模板的信息密度等级，包括：

- 人物姿态。
- 画面构图。
- 色彩关系。
- MG 元素。
- 图层关系。
- 镜头运动。
- 节拍触发。
- 转场因果。
- 视觉稳定要求。
- 负向约束。

不得把高密度模板转写成简单故事梗概。

### 4.4 画面完成度等级

保留原模板的视觉品质目标，例如：

- 高级 Editorial MG。
- 日系硬边赛璐璐。
- 高级时装杂志排版。
- 瑞士平面设计。
- 图形化、海报化、艺术画册化。
- 精确裁切、正负形、网格、留白、套印、纸张与版面系统。

这里继承的是**画面品质和设计语言等级**，不是固定继承某一种颜色或某一组符号。

### 4.5 转场设计方法

原模板依靠图形匹配、正负形替换、人物局部、纸张翻折、轮廓延展等方式转场时，新版本继续保持“前镜头元素自然变成后镜头主体”的因果关系。

不得退化为普通淡入淡出、随机闪白或无因果硬切。

---

## 5. 必须为新主题重构的内容

以下内容不应因为原模板中存在而默认沿用：

- 人物性别与身份。
- 人物关系。
- 发型、服装、饰品和纹样。
- 武器和道具。
- 城市、房间、自然环境或世界观。
- 核心视觉母题。
- 颜色系统。
- 主题象征物。
- 情绪表达方式。
- 标题与结尾意象。
- 高潮中的视觉冲突形式。

新主题需要形成自己的视觉词汇表。

例如目标主题为“多重人格”时，应围绕身份争夺、人格切换、性别交错、镜像错位、表情冲突、身体控制权、记忆断层等主题机制设计视觉，而不是把原模板中的武器、月相、昆虫、酒杯逐项换成另一组形状相近的物体。

---

## 6. 禁止机械替换

以下转写方式不合格：

| 不合格方式 | 问题 |
| :-- | :-- |
| 刀换成枪，月亮换成眼睛，蝴蝶换成乌鸦 | 只替换名词，叙事机制没有变化 |
| 原模板是蓝白，新主题仍强制蓝白 | 把表面配色误当成画面等级 |
| 原模板角色为女性，新主题仍默认只能是女性 | 把角色设定误当成结构骨架 |
| 原模板每拍只允许单锚点，新主题要求炸裂仍完全照搬 | 规则与目标情绪发生冲突 |
| 原模板所有禁止项原样复制 | 新主题受到无关约束 |
| 分镜时间段全部重写成另一套粗粒度结构 | 丢失模板真正需要继承的镜头精度 |

转写必须先识别每个原元素在镜头中的**功能**，再为新主题寻找新的实现方式。

---

## 7. 主题视觉系统

生成分镜前，需要先建立目标主题自己的视觉系统。

### 7.1 主题核心冲突

明确视频持续表达的核心关系，例如：

- 自我与另一个自我。
- 控制与失控。
- 现实与幻觉。
- 神圣与污染。
- 秩序与崩塌。
- 欲望与禁忌。
- 记忆与遗忘。

所有主要人物、动作、元素和转场都应服务于这一核心关系。

### 7.2 角色系统

角色设计至少明确：

- 主体是谁。
- 角色之间是什么关系。
- 性别是否固定。
- 人格或状态如何区分。
- 哪些外形特征必须稳定。
- 哪些局部可以发生视觉变化。
- 角色的危险感、魅力或压迫感通过什么动作表现。

角色区分优先使用：

- 眼神。
- 嘴角。
- 姿态。
- 手势。
- 发丝状态。
- 饰品与纹样。
- 色彩局部变化。
- 版面位置。
- 镜像关系。

避免只依赖换衣服、换发色、换脸完成状态变化。

### 7.3 核心视觉母题

建立 3–7 组能够反复变形的主题母题。

合格母题需要同时满足：

- 与目标主题有明确关系。
- 轮廓清晰，适合图形化。
- 可以在多个镜头中改变尺度和形态。
- 可以承担转场。
- 可以从角色局部、道具或场景自然产生。

母题之间应具备形状或运动上的可转换关系。

### 7.4 色彩系统

颜色根据主题选择，不绑定原模板配色。

需要明确：

- 主底色。
- 人物主体色。
- 高亮色。
- 危险色。
- 爆发段临时介入色。

颜色变化必须具备叙事功能，例如人格接管、危险升级、高潮爆发、空间翻转，而不是随机换色。

### 7.5 场景与空间

场景需要主题化，而不是把原场景换皮。

场景可以是现实空间，也可以是心理空间、抽象版面、内部世界、档案系统、舞台、城市、房间或非现实结构。

无论场景如何变化，都应继续遵守原模板对应的视觉媒介规则，例如二维、平面、海报化、杂志化、赛璐璐化。

---

## 8. 参考图使用规则

人物或视觉参考图用于提取设计方向，不默认一比一复刻。

可以提取：

- 人物气质。
- 发型轮廓。
- 服装复杂度。
- 手势表现。
- 饰品密度。
- 纹样语言。
- 眼神强度。
- 光色关系。
- 黑白和彩色区域比例。
- 构图压迫感。

参考图中的性别、配色、场景、具体服装、具体纹样均可根据目标主题重新设计。

最终人物应属于目标主题自己的角色系统。

---

## 9. 分镜转写规则

每个原镜头先按“功能”理解，再生成对应的新主题镜头。

一个镜头至少需要明确：

1. 当前时间段。
2. 当前视觉锚点。
3. 人物或核心元素的动作。
4. MG、版面或空间变化。
5. 当前节拍触发的主要事件。
6. 前一镜头元素如何延续到当前镜头。
7. 当前镜头结尾如何生成下一镜头的主体结构。

### 9.1 功能映射

原镜头中的具体元素不需要保留，但镜头功能可以保留。

例如：

- 原镜头负责“第一次角色显影” → 新主题仍需要完成角色第一次正式显影。
- 原镜头负责“第一次危险信号” → 新主题设计自己的危险信号。
- 原镜头负责“角色局部逐拍建立” → 新主题使用自己的角色局部和视觉语言完成逐拍建立。
- 原镜头负责“高潮前绝对静止” → 新主题保留节奏功能，但静止画面内容重新设计。
- 原镜头负责“核心母题聚合为转场” → 新主题使用自己的核心母题完成聚合。

### 9.2 每拍只描述明确变化

高密度不等于所有东西同时运动。

普通节拍中需要明确：

- 什么保持不动。
- 什么发生变化。
- 什么成为当前锚点。
- 变化持续多少拍或多少帧。

高潮允许提高同时运动元素数量，但必须存在主次层级。

---

## 10. 节奏与信息密度

继承原模板的节奏组织能力，不机械继承每一条密度限制。

常用节奏单位包括：

- 留白。
- 缓慢建立。
- 局部异变。
- 短促爆发。
- 绝对静止。
- 高密度高潮。
- 瞬间抽空。
- 重新排版。

### 10.1 秩序段

用于角色建立、情绪蓄压和视觉辨识。

建议保持：

- 单一或少量主锚点。
- 清晰留白。
- 辅助元素错峰运动。
- 强构图秩序。

### 10.2 爆发窗

目标主题明确要求疯感、混乱感、炸裂感、失控感时，可以设置短时高密度爆发窗。

爆发窗可以允许：

- 多个角色局部同时抢占版面。
- 多人格或多状态在不同页面中撞入。
- 画面切片数量短时间增加。
- 多层符号、手势、发丝、眼睛、嘴角、纹样相互覆盖。
- 颜色短暂失去原有稳定关系。
- 版面快速翻折、挤压、错位和重组。

爆发窗必须满足：

- 持续时间短。
- 高优先级元素数量明确。
- 元素来自已经建立的主题视觉系统。
- 运动存在节拍顺序。
- 峰值后迅速归零、抽空或重新建立单一锚点。

禁止用随机 glitch、电视噪点、乱码、粒子堆积代替真正的视觉失控。

---

## 11. 强度要求的优先级

用户追加的情绪与强度要求属于有效设计约束。

当目标要求与原模板某条具体限制发生冲突时，按以下顺序处理：

1. 保留原规则解决的问题。
2. 改写与目标情绪冲突的具体实现方式。
3. 保持画面可读性和生成稳定性。

例如：

原模板通过“任何时刻只有一个主视觉锚点”避免画面失控；目标主题明确要求炸裂和混乱时，不需要原样保留该数字限制，可以使用“常态单锚点 + 短时多锚点爆发窗 + 爆发后瞬间抽空”。

继承的是**控制混乱的机制**，不是某一个固定数字。

---

## 12. 图形匹配转场

所有重要转场优先使用视觉因果完成。

可使用：

- 轮廓匹配。
- 圆形、直线、斜线、裂缝等几何匹配。
- 颜色块扩张与收缩。
- 人物眼睛、嘴唇、手指、发丝等局部匹配。
- 负形匹配。
- 页面、镜片、面具、框线或场景边缘翻折。
- 动作方向匹配。
- 纹样延展。
- 剪影变形。
- 遮挡物覆盖全屏后变为下一场景。

每个重要转场都要能回答：

> 前一个镜头中的哪个东西，如何变成了下一个镜头中的什么东西？

无法回答时，转场属于无因果转场，需要重写。

---

## 13. 严格限制的转写

严格限制分为两类。

### 13.1 通用质量限制

通常可以继承：

- 不突然写实化。
- 不发生人物脸部漂移。
- 不出现额外手指和肢体融合。
- 不发生道具比例漂移。
- 不使用无意义闪白。
- 不使用廉价故障艺术。
- 不使用无意义粒子堆叠。
- 不使用无叙事作用的随机元素。
- 不使用普通淡入淡出替代设计型转场。
- 不让所有元素无层级同时高速运动。

### 13.2 主题相关限制

需要重新评估：

- 固定颜色禁令。
- 固定武器禁令。
- 固定人物数量限制。
- 固定场景限制。
- 固定怪物限制。
- 固定文字与标题限制。
- 固定视觉母题限制。

与新主题无关的限制应删除，不得为了“像原模板”而继续保留。

---

## 14. 最终提示词结构

最终提示词沿用原模板的章节层级。

常见结构：

```markdown
# [目标主题 / 项目名称]

[整体定位、时长、媒介与核心视觉叙事]

## 美术风格

[最终美术规则]

## 角色

[最终角色设定]

## 分镜

### 0–3 秒

第一拍｜...

第二拍｜...

第三拍｜...

### 3–6 秒

...

## 严格限制

- ...
- ...
```

原模板存在多个视频段落时，每一段分别保持完整的美术、角色、分镜与限制结构，或按原模板既有组织方式处理。

---

## 15. 最终文档要求

最终交付文档只出现可以直接使用的提示词内容。

不得出现：

- 原模板分析。
- 转写过程。
- 元素替换表。
- “保留 / 修改 / 删除”说明。
- 版本比较。
- 用户反馈记录。
- 设计理由。
- 对话内容。
- “V2”“加强版”“修改版”等版本过程痕迹，除非版本号本身属于正式交付命名要求。

允许出现：

- 最终美术定义。
- 最终角色定义。
- 最终分镜。
- 最终标题。
- 最终严格限制。
- 必要的生成参数。

---

## 16. 质量检查

提交前逐项检查：

### 结构

- [ ] 是否保留原模板的结构逻辑。
- [ ] 是否保持原模板的分镜描述粒度。
- [ ] 是否保持原模板的提示词密度。
- [ ] 是否保持原模板的画面完成度等级。

### 主题

- [ ] 人物是否真正服务于新主题。
- [ ] 核心视觉母题是否属于新主题。
- [ ] 场景是否经过主题化设计。
- [ ] 配色是否根据主题建立，而非机械沿用原模板。
- [ ] 高潮是否表达目标主题的核心冲突。

### 分镜

- [ ] 每个镜头是否存在明确视觉锚点。
- [ ] 每一拍是否知道什么在动、什么不动。
- [ ] 转场是否具有图形或动作因果。
- [ ] 高密度爆发是否存在主次层级。
- [ ] 爆发后是否存在停顿、抽空或重新建立秩序。

### 发散

- [ ] 是否避免逐项同义替换原元素。
- [ ] 是否允许人物性别、角色关系、色彩、道具、场景和母题根据主题变化。
- [ ] 是否只继承原元素的镜头功能，而不是原元素本身。

### 文档

- [ ] 是否可以直接复制给生成模型。
- [ ] 是否删除修改过程和解释性文字。
- [ ] 是否删除“原版、改为、这一版、相比、保留了”等对话或版本过程痕迹。
- [ ] 是否符合 [`文档编写规范.md`](./文档编写规范.md)。

---

## 17. 最终判定标准

合格的主题转写同时满足以下条件：

1. 不看原模板，也能独立理解并直接生成。
2. 看过原模板，可以识别出相同的结构能力、镜头精度、节奏能力和画面等级。
3. 新主题拥有明显独立的人物、元素、色彩、意象和视觉冲突。
4. 不存在“把原元素换个名字”的机械改写感。
