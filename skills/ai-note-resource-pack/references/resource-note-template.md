# 资料笔记模板

```markdown
# 第【期数】期｜【如何解决 + 具体问题】

## 1. 我遇到的问题

【用一至三段写具体问题。只使用原始输入中真实存在的场景和现象。】

## 2. 分析

【承接问题，解释为什么会发生。把事实、分析和推测区分开。结尾指出真正需要补上的判断或机制。】

## 3. 如何解决

【先承接分析：既然原因是……，方法就需要……。随后写能执行的做法；不要直接堆步骤。】

## 4. 资料包

【说明本资料基于前面的哪项分析或方法整理。】

【说明适合用于什么位置、任务或时机，以及最终整理成什么类型。】

以下是整理后的【资料类型】：

【资料本体】
```

## 标题锁定

- 一级标题：`# 第【期数】期｜【标题】`
- 二级标题只有四个：
  - `## 1. 我遇到的问题`
  - `## 2. 分析`
  - `## 3. 如何解决`
  - `## 4. 资料包`

不要增加「总结」「使用边界」「与视频的关系」「相关链接」等固定章节。需要表达的边界应写进分析、解法或资料本体中。
