# 系列设计系统

目标：信息流中 1 秒内识别「同一系列」且「在讲什么问题」。

## 标题公式（片头 + 封面共用）

- `如何解决 + 具体问题`
- 或 `AI + 场景 + 方法/避坑`

禁止标题无法对应内容；禁止标题含进群领包。

## 封面

1. 大号标题（约 40–50% 面积，高对比）
2. 关键词高亮
3. 可选简洁符号（勿堆截图墙）
4. 固定系列角标位置（全系列统一）

封面画幅与成片一致（默认 7:5）。

## 画幅（默认）

- **默认：7:5，画布 1400×1000**
- 仅当用户明确要求其他比例（如 9:16）时覆盖，并在 BRIEF / render-notes 中记录
- 信息优先：主内容居中偏上；边缘留足安全区

## style_lock

在 `theme/` 集中定义，全片只读 token：

- 画布：`width: 1400, height: 1000`（除非 BRIEF 覆盖）
- 背景：深或浅**单集锁一种**，禁止无说明混用
- 主色/强调色：关键词与编号
- 标题/正文字体：中文可读无衬线
- 编号卡片：统一圆角与底衬
- 段间转场：与 playbook 全局规则一致，系列级锁死

变更 style_lock 或默认画幅 = 系列视觉变更，需重渲相关集。

## 安全区（7:5 / 1400×1000）

- 关键文字距左右边缘建议 ≥ 64px
- 距上下边缘建议 ≥ 72px
- 避免把主标题贴边

## 与四段配方的关系

本文件管「长得像不像一套」与画幅；`four-act-motion-playbook.md` 管「每一段怎么动」。  
实现时两者同时满足。

## 发布物料（PUBLISH.md）

- 标题与封面一致或极短变体
- 描述：价值摘要 + **可选**进群引导（仅此处）
- 建议置顶评论：互动 + 可选领资料说明

视频成片不得出现上述引导。
