# 四段式镜头配方表（强制路由）

动效不是装饰，而是段落职责的可视化。  
Agent **只能**从本表选型；禁止凭空发明新运动风格。

设计顺序：

```text
文案段落角色 → 本段唯一主焦点 → 允许配方 ID → 参数带内实现 → hold → 退场/切段
```

默认画布 **7:5（1400×1000）**；布局与字号按此比例设计。用户明确要求其他比例时，安全区按比例缩放，配方语义不变。

---

## 全局硬规则

1. **每镜一个主焦点**：主文案或当前编号卡片；最多一个辅助符号。
2. **页隔离**：换段清空上一页；禁止半透明残留假连续。
3. **入场必动、结论必停**：关键信息入场后 hold 足够阅读（默认 ≥ 18–30 帧 @30fps，随字数增加）。
4. **缓动库锁定**：全片仅使用下列集合，禁止每集新曲线。  
   - 入场：`Easing.out` 类短入场  
   - 退场：`Easing.in` 或短 fade  
   - 列表：固定线性 stagger（帧间隔恒定）  
   - 可选一次强调：短 scale 脉冲后回到 1.0
5. **安全区**：默认 1400×1000 下，关键文字距左右 ≥ 64px、距上下 ≥ 72px。
6. **段间转场**：全系列只选一种——（默认）硬切 + 新段入场，或统一短 dissolve 8–12 帧。
7. **禁止**：持续无意义漂浮、随机抖动、装饰粒子作为主运动、与口播无关的循环动画。

---

## 文案 → 配方判定

```text
疑问句 /「你有没有…」/ 痛点场景     → 段1，配方 A1 或 A2（需两词对比时 A3）
「本质是 / 原因是 / 底层…」         → 段2，配方 B1（需两步因果时 B2；需隐喻时 B3）
「第一/第二/三个方法」或明确条数   → 段3，必须 C1 或 C2；条数=口播条数且顺序一致
「你平时…？/评论区…」               → 段4，必须 D1；禁止任何转化文案入镜
```

---

## 段 1 · 共鸣（允许：A1 / A2 / A3）

**职责**：让观众对上号。  
**主焦点**：问题句或痛点关键词。

| ID | 名称 | 运动摘要 | 适用文案 |
|----|------|----------|----------|
| **A1** | 问题句大字入场 | 整句自下方轻移入或 opacity 0→1 + translateY 正向收束；短 ease-out（8–12 帧）；随后 hold | 单句痛点/提问 |
| **A2** | 关键词高亮 | 先 A1 入场并 hold；再对**一个**痛点词做一次颜色或 scale 脉冲（6–10 帧）后复原 | 句中有明确痛点词 |
| **A3** | 反差两词 | 仅两个短词（如「编造」vs「真实」）左右或上下先后 reveal；间距稳定；无第三条 | 文案本身是二元反差 |

**禁止**：解决方案编号；流程图；≥3 张卡片；装饰粒子。

---

## 段 2 · 本质（允许：B1 / B2 / B3）

**职责**：一句话说清为什么。  
**主焦点**：机制短句或因果中的「结果」一侧。

| ID | 名称 | 运动摘要 | 适用文案 |
|----|------|----------|----------|
| **B1** | 机制短句揭示 | 居中短句：opacity 0→1，可选 blur 高→0 或 letter-spacing 宽→正常；12–18 帧内完成入场后 hold | 单句机制 |
| **B2** | 因果两步 | 最多两态：先因后果；第二态出现时第一态降权或上移让位；禁止第三态 | 口播含清晰两步 |
| **B3** | 隐喻图标 + 短标签 | 单一图标与机制语义一致 + 短标签；图标与文字同一入场或图标先 4 帧；全系列图标风格统一 | 机制适合一个稳隐喻 |

**禁止**：>2 步长链路；无语义 3D/粒子；与口播冲突的隐喻；循环漂浮。

---

## 段 3 · 方案（允许：C1 / C2 / C3）

**职责**：1–3 条可执行骨架。  
**主焦点**：当前编号条。  
**强制**：画面条数 = 口播条数；顺序一致；口播未点到的条不得提前高亮完成。

| ID | 名称 | 运动摘要 | 适用文案 |
|----|------|----------|----------|
| **C1** | 编号卡片 stagger | 卡片 1→2→3 依次入场；固定 stagger 4–8 帧/项；入场后全部保持可读；最多 3 项 | 口播枚举多条 |
| **C2** | 单条聚焦 | 同时最多三条在场；**当前**条提亮/略放大，其余降 opacity；随口播切换焦点 | 需要逐条讲解 |
| **C3** | 步骤短标签 | 动词短标签（如「先列未知」）；形式同 C1/C2，文案更短 | 标签极短时 |

**禁止**：一次甩出完整长提示词；>3 条；顺序与口播不一致；条未到位口播已过完。

---

## 段 4 · 反问（允许：D1 / D2）

**职责**：促互动、干净收尾。  
**主焦点**：反问句。

| ID | 名称 | 运动摘要 | 适用文案 |
|----|------|----------|----------|
| **D1** | 反问句稳态 hold | 短入场后**长时间静止**；不抢戏 | 标准反问收尾 |
| **D2** | 轻量收束 | 在 D1 基础上，系列角标或收束短字轻 fade（可选）；无跳转感 | 需要极轻品牌收束 |

**禁止**：进群、领资料、私信、按钮式强 CTA、新主题标题。

---

## 参数带（@30fps，不得无故越界）

| 参数 | 默认区间 |
|------|----------|
| 单元素入场 | 8–12 帧 |
| 列表 stagger | 4–8 帧/项 |
| 关键词脉冲 | 6–10 帧后回到常态 |
| 段间 dissolve（若选用） | 8–12 帧 |
| 主信息 hold | ≥ 18 帧，长句增加 |

---

## STORYBOARD 必填字段（每段）

```text
- act: resonance | essence | solution | question
- recipe: A1 | A2 | ... | D2
- focus: 本段主焦点文案
- entrance: 简述（须匹配配方）
- hold_frames: 数字
- exit: 切段方式（遵从系列转场锁）
- forbidden_check: 已确认未使用本段禁止项
```

缺 `recipe` 或 `recipe` 不属于该段允许集 → Gate 失败，不得进入实现。
