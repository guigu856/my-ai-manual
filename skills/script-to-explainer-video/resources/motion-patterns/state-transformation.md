# 状态转化与认知重构

## 适用语义

用于同一对象从旧状态转向新状态，尤其适合：

- “你以为 X，其实 Y”
- 方法升级
- 对象角色变化
- 旧解释被新解释替代
- 混乱逐渐收束为清晰结构

## 不适用

- 两个完全独立对象的平行对比
- 单向多步骤流程
- 父子层级

## 对象模型

- persistent_subject：跨状态保持身份的对象
- old_frame：旧解释或旧结构
- contradiction：导致旧状态无法维持的矛盾
- new_frame：新解释或新结构
- preserved_evidence：前后状态共享的信息

## 空间结构

优先在同一空间完成重构，让观众感知“对象没变，理解变了”。可使用：

- 同一中心对象周围关系重组
- 旧标签退出、新标签进入
- 多个外围对象降权，真正变量聚焦
- before/after 短暂并列后合并到新状态

## 推荐状态链

```text
OLD_STATE
→ OLD_STATE_REINFORCED
→ CONTRADICTION
→ FREEZE_OR_BREAK
→ NEW_VARIABLE_REVEALED
→ RELATION_REBUILT
→ NEW_STATE_HOLD
```

## 主要事件

- accumulate
- compare
- interrupt
- replace
- transform
- focus
- collapse

转折应发生在口播的矛盾或关键词 cue 附近，不能提前完成新状态。

## 连续性

persistent_subject 必须保持身份、主要位置或可追踪运动路径。若完全换画面，认知重构会退化为两个无关镜头。

## 风险

- 新结论过早出现
- 旧状态没有建立充分，转折缺乏力量
- 使用无关闪白或故障效果代替逻辑变化
- 旧对象全部消失，观众无法识别前后是同一问题
- 结论只由大字宣布，没有通过关系重构表现

## 验收

- 旧状态为何成立是否清楚
- 矛盾是否可见
- 哪个对象跨状态保持身份
- 新状态改变了哪条关系
- 最终画面是否比字幕多提供一层理解
