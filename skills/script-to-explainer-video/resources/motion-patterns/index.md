# 动效类型资源索引

这里存放可组合、可替换的概念动效类型。资源文件描述某类脚本适合怎样的视觉结构，不替代主 Skill 的生产方法、音频主时钟、字幕契约和质量门槛。

## 选择流程

1. 从脚本提取语义拓扑：线性链路、枚举展开、层级结构、循环反馈、对比映射或状态重组。
2. 一个场景先选择一个主拓扑。
3. 读取资源的节点模型、状态链、几何约束、cue 契约和验收清单。
4. 使用 `timeline.json` 的 cue 帧实例化资源；脚本语义优先于资源示例。
5. 新类型先新增资源文件，再决定是否扩展本索引。

## 未归档类型

没有匹配的 archived 资源时，可以为当前场景写局部状态链和布局表，并在场景数据中记录 `resource_status: pending`。这次局部设计经过跨项目验证后，再单独提炼为资源文件；临时方案不自动升级为通用规则。

## 资源文件契约

每个 archived 类型资源至少包含：

- `id` / `name` / `version`
- 适用语义与边界
- 节点模型与空间布局
- 状态链与入退场顺序
- cue 驱动的动效节拍
- 文案与字幕职责
- 视觉风险与验收清单

资源只提供结构化视觉决策；具体项目仍由脚本、配音实测时长和 `timeline.json` 决定。
