# 动效类型资源索引

这里存放可组合、可替换的概念动效类型。资源文件描述“某类脚本适合怎样的视觉结构”，不替代 SKILL.md 的生产方法、音频主时钟、字幕规范和质量门槛。

## 选择流程

1. 从脚本提取语义拓扑：线性链路、枚举展开、层级结构、循环反馈、对比映射或状态重组。
2. 选择一个主类型资源；一个场景先保持一个主拓扑。
3. 读取该资源的节点模型、状态链、几何约束、节拍契约和验收清单。
4. 用 timeline.json 的 cue 帧实例化资源；脚本语义优先于资源示例。
5. 新类型先新增资源文件，再决定是否需要扩展 SKILL.md 的通用路由。

## 类型索引

| 语义拓扑 | 资源 | 适用脚本 |
|---|---|---|
| 线性链路 / 关系重组 | [concept-chain.md](concept-chain.md) | “调用 → 连接 → 上下文”“输入 → 处理 → 输出”等逐步建立关系的观点 |
| 枚举展开 | 待归档 | 配音明确逐项列出同级概念 |
| 层级展开 | 待归档 | 从总概念逐层展开到子模块 |
| 循环反馈 | 待归档 | 状态回流、观察—决策—执行闭环 |
| 对比映射 | 待归档 | 两种方案、前后状态或输入输出的并行对照 |

## 资源文件契约

每个类型资源至少包含：

- id / name / version
- 适用语义与边界
- 节点模型与空间布局
- 状态链与入退场顺序
- cue 驱动的动效节拍
- 文案与字幕职责
- 视觉风险与验收清单

资源只提供结构化视觉决策；具体项目仍由脚本、配音实测时长和 timeline.json 决定。
