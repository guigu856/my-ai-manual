# 对比映射

## 适用语义

用于两种方法、两个状态、旧认知与新认知之间的对照。比较对象必须共享明确维度。

## 不适用

- 单向步骤流程
- 父子层级
- 没有共同尺度的随意并列

## 对象模型

- subject_a / subject_b
- shared_dimensions
- differences
- decision 或 conclusion

## 空间结构

优先使用：

- 左右并列
- 上下并列
- 共享坐标轴
- 同一对象的 before / after

两侧使用一致尺度、边距和信息密度，避免通过视觉偏置替代真实结论。

## 推荐状态链

```text
CONTEXT
→ A_ESTABLISHED
→ B_ESTABLISHED
→ SHARED_DIMENSION
→ DIFFERENCE_HIGHLIGHTED
→ CONCLUSION
```

## 主要事件

- reveal
- align
- compare
- de-emphasize
- focus
- replace（仅认知重构时）

## 连续性

如果对比最终导向一个新判断，可保留共享维度，把 A/B 收束为结论。不要在结论后继续让两侧保持同等视觉权重。

## 风险

- A/B 使用不同尺度造成误导
- 一侧文字明显更多
- 对比维度不明确
- 结论在比较完成前提前出现
- 颜色被误解成价值判断

## 验收

- 观众是否能立刻说出比较维度
- 两侧是否真正可比
- 差异是否由内容而非视觉作弊产生
- 结论是否来自前面展示的差异
