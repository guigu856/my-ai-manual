# 生产剖面

生产剖面用于限制状态空间。它不是视觉风格，而是决定场景如何组织、对象是否跨场保留以及怎样验收。

## `page-isolated`：默认

适用：观点口播、知识讲解、复盘、方法论、列表和对比，尤其是 3 分钟以内的视频。

约束：

- 一页只承载一个可复述的判断。
- 每页拥有独立根容器，换页时上一页对象全部退出。
- 页面内允许逐项出现，但不允许上一页卡片以低透明度残留到下一页。
- 页面之间只共享全局背景、字幕层和固定页面边角；不共享内容对象。
- 一页默认最多四个内容组、一个主要焦点、一个主运动关系。
- 翻页时间来自实测音频 cue，不从估算 `data-duration` 或组件计时器推导。

它的目的不是让视频变成普通幻灯片，而是让每段视觉状态可独立验证、可替换、可重渲染。

## `continuous-diagram`：有条件使用

只在跨场对象变换本身承担解释任务时使用，例如：

- 同一结构从错误模型逐步重构为正确模型。
- 同一对象的关系、层级或反馈回路连续变化。
- 观众必须记住对象身份，切页会破坏理解。

使用前在 `STORYBOARD.md` 记录：

- 必须保留的对象及语义理由。
- 每个对象跨场前后的身份、位置和层级。
- 退出对象清单。
- 最多一个跨场锚点；更多对象需要在 Gate 3 明确批准。
- 密集抽帧区间和失败时退回 `page-isolated` 的方案。

以下理由不足以选择连续场景：

- “看起来更高级”。
- “画面更丰富”。
- “想让上一页有一点残影”。
- “不想做普通幻灯片”。

## 选择规则

1. 先尝试把内容写成一页一个判断。
2. 若页面隔离不会损失对象身份或因果关系，使用 `page-isolated`。
3. 若确实需要连续结构，列出跨场对象并证明其解释作用。
4. 复杂度预算或验收失败时，优先降级为页面隔离，不在旧结构上继续堆补丁。
