# 动效语言

动画不是装饰层，而是视觉状态之间的语义变化。

## 设计顺序

```text
视觉任务
→ 起态与终态
→ 状态之间的逻辑关系
→ 运动行为
→ cue 对齐
→ easing、duration 和细节
```

不要从“加一个缩放”“做一个转场”开始。

## 基础动作

### reveal

让新对象进入可见状态。适合首次建立对象或结论。

### connect

建立节点、对象或因果之间的关系。连线应从锚点计算，不穿过节点和文字。

### accumulate

逐步增加元素，表达堆积、增长、压力或证据累积。

### separate

把原本混在一起的对象分开，表达分类、分歧或边界。

### compare

在共享维度中展示差异。应保持可比对象的尺度、位置或坐标一致。

### transform

同一对象改变形态或角色，表达状态变化和连续性。

### replace

旧解释退出，新解释进入。适合认知重构，但要避免无缘由跳变。

### collapse

多个元素收束为一个结论、规律或核心对象。

### focus

通过降权其他元素，将注意力集中到目标对象。

### loop

表达反馈、循环和重复机制。循环必须有可识别的回流路径。

### hold

保持稳定状态，给观众阅读和理解时间。Hold 也是动画设计的一部分。

## 组合动作

组合动作必须写明顺序：

```text
accumulate → overload → collapse
reveal → connect → focus
compare → contradiction → replace
```

不要只写“动态出现”“丝滑转场”等不可执行描述。

## 时间契约

- Event 绑定 cue 或 State 区间
- duration 根据相邻 cue 间距和信息复杂度决定
- 同类动作使用统一 motion token
- 复杂关系建立速度应慢于装饰元素退出速度
- 重要终态必须保留足够 hold
- 不因口播变长而简单拉伸所有动画；应调整状态分配

## Easing 语义

- `ease-out`：对象快速进入注意，随后稳定
- `ease-in`：对象离开或进入不可逆变化
- `ease-in-out`：连续搬移和重组
- `spring`：轻量强调或具物理感的对象，不用于严肃数据和所有文字
- `linear`：进度、持续流动和真实速度表达

同一视频控制 easing 种类。除非语义需要，不为每个 Scene 发明新曲线。

## 空间纪律

- 所有对象使用统一坐标系
- 起点、终点和锚点明确
- 连线端点从对象边界计算
- 移动路径避开文字和字幕安全区
- 转场期间也必须满足层级和遮挡约束
- 共享元素跨场时保持同一身份，不复制成两个短暂重叠对象

## 强调预算

强调依赖对比。每个 Beat 最多设置一个主要强调对象。

可用手段：

- 尺寸变化
- 色彩变化
- 空间聚焦
- 短暂停顿
- 背景降权
- 声画同步落点

如果所有元素都在移动、变色或弹跳，等于没有强调。

## 情绪

运动方式可以表达：

- 缓慢漂移：思考、克制
- 快速切入：紧迫、明确
- 堆积：焦虑、失控
- 突然中断：冲突、转折
- 收拢：清晰、归纳
- 机械重复：枯燥、荒诞

情绪运动不得破坏信息可读性。

## 禁止项

- 与口播无关的持续漂浮
- 为避免静止而添加随机抖动
- 依赖 `Date.now()`、实时计时器或随机数
- 元素先动，观众却不知道它代表什么
- 只设计最终帧，不设计中间状态
- 转场覆盖核心结论的阅读时间
