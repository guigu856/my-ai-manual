# 音频与时间轴契约

## 两类时间

### 规划时间

用于脚本和分镜阶段判断篇幅、节奏和场景数量。可以根据字数、语速和停顿估算，但不得直接进入最终渲染。

### 执行时间

来自最终配音文件的实测 cue。通过音频验收后，它是字幕、场景、状态和动画事件的唯一主时钟。

## 正确顺序

```text
叙事与分镜锁定
→ 生成最终配音
→ 获取句级/词级 cue
→ 音频验收
→ 编译 render-plan
```

不是“先生成音频，再想画面”。若分镜阶段修改口播，应在 Gate 3 后一次性生成最终配音。

## audio-meta.json

至少包含：

```json
{
  "schema_version": "1.0.0",
  "audio_file": "audio/master.wav",
  "audio_hash": "sha256:...",
  "sample_rate": 48000,
  "channels": 1,
  "duration_seconds": 42.318,
  "spoken_units": [
    {
      "id": "SU03",
      "beat_id": "B03",
      "text": "真正的问题，往往不是工具掌握得不够多。",
      "start": 8.42,
      "end": 11.76,
      "words": [
        {"text": "真正", "start": 8.42, "end": 8.91}
      ]
    }
  ]
}
```

句级 cue 为必需；词级 cue 可用时必须保留。无法获得可靠词级时间时，不得伪造精确时间，可使用句级 cue 加相对 offset。

## 配音生成

- 用户未指定声线时，默认使用剪映软件中的“真人口播女”音色
- 该默认值指向用户本机剪映里的具体音色，不等同于任意女声、自然女声或供应商推荐女声
- 优先让剪映直接生成或导出该音色的最终音频；自动化链路只有在明确选中该音色时才能生成最终配音
- 如果当前执行环境不能操作剪映或不能确认已选中该音色，保留 `voice_preference: 剪映软件中的真人口播女音色`，并将该环节标记为待从剪映导出，不得静默使用其他声线
- 声线服从用户要求和脚本气质
- 试听优先于供应商标签
- 避免机器人音、电流感、金属共振、客服腔、新闻腔和广告腔
- 技术名词、英文缩写、多音字和数字必须试听
- 逐段生成时先统一采样率、声道和响度再拼接
- 拼接后重新探测总时长和边界

## 停顿

停顿是叙事的一部分：

- 普通短句间隔可短
- 转折前后应给认知切换留空间
- 复杂结论后应留稳定阅读时间
- 不统一硬写 0.3 或 0.5 秒；根据语义和试听调整

所有首尾静音和段间静音都计入执行时间。

## 信号级验收

至少检查：

- 文件可解码
- 无削波和异常爆音
- 无异常长静音
- 声道和采样率一致
- 语速与内容复杂度匹配
- cue 不重叠、不逆序、覆盖全部 Spoken Unit
- `duration_seconds` 与媒体探测一致
- 人声响度全片稳定

## BGM 与音效

- 默认不添加 BGM
- 使用时确认版权和可发布范围
- 人声始终是主要信息层
- BGM 在旁白下自动 duck，不得掩盖辅音和句尾
- 禁止用持续嗡鸣、低频脉冲或噪声假装科技感
- SFX 只用于动作反馈、结构转折和节奏落点，不给每个元素配音效

## Hash 与失效

`audio_hash` 必须进入 `render-plan.json`。音频文件或 cue 改变后：

- 旧 render plan 失效
- 旧字幕渲染失效
- 旧 final.mp4 失效

不得用旧审核结果继续渲染。
