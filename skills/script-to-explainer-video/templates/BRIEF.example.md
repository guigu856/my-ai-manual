# 创作目标

观众看完后应能复述：

> AI 工具掌握得再多，也无法替代对任务的清晰定义。

# 必须保留

- “工具数量”和“任务表达”的对比
- 不把问题归因于模型不够强

# 可以删除

- 工具清单
- 与核心判断无关的个人经历

# 风险

- 不能把“表达清楚”简化成写更长的提示词
- 需要说明判断标准和上下文同样重要
