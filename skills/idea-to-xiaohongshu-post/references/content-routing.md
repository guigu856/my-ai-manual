# 内容路由

## 路由目标

先判断这份材料最适合怎样被读，再决定页数和版式。不要默认把所有内容都切成“封面 + 五个要点 + 总结”。

## 类型判断

| 类型 | 识别信号 | 推荐推进 | 常用页数 |
|---|---|---|---:|
| 观点型 | 有明确立场、认知冲突、纠偏或反常识判断 | 冲突 → 区分 → 机制 → 边界 → 价值 → 提问 | 6–9 |
| 教程型 | 有前提、步骤、检查点和失败条件 | 结果 → 前提 → 步骤 → 检查 → 错误 → 清单 | 6–9 |
| 比较型 | 同一问题下存在两个以上选择 | 共同问题 → 维度 → 差异 → 边界 → 选择 | 5–8 |
| 清单型 | 条目相对独立但需要分类和选择规则 | 场景 → 分类 → 条目 → 规则 → 汇总 | 5–8 |
| 故事型 | 时间、人物或认识发生变化 | 场景 → 变化 → 发现 → 重新理解 → 余味 | 6–9 |
| 证据型 | 结论依赖截图、数据、实验或案例 | 结论 → 证据 → 解释 → 限制 → 判断 | 5–9 |

## 观点型作品

观点型图文的核心不是“把观点说得更响”，而是让读者看见判断是怎样成立的。

至少包含以下三项：

1. 区分：两个容易混在一起的概念有什么不同。
2. 机制：差异如何产生结果。
3. 边界：这个判断在什么情况下不成立或需要补充。

只有立场、没有机制时，卡图会退化成大字报。只有机制、没有具体冲突时，封面会缺少进入理由。

## 何时不做图文轮播

- 内容主要靠表情、语气、现场动作或声音感染力成立：优先视频。
- 需要完整论证、引用和大量上下文，压缩后会改变结论：优先长笔记或文章。
- 只有一句口号，没有事实、机制、例子或边界：先继续发展想法。
- 用户只要标题、正文或平台改写，明确不要出图：交给文稿 Skill。
- 用户只要一张封面：交给封面或图像设计 Skill。

## 页数判断

- 5 页以下：检查是否只是单张海报被强行拆开。
- 5–9 页：默认区间。
- 10–12 页：需要真实的信息增量或证据密度。
- 12 页以上：优先拆成系列或长笔记。

平台允许数量和比例会变化。作品页数首先服从内容结构，再核对当前平台约束。

## 素材判断

| 内容关系 | 优先视觉 |
|---|---|
| 两种选择或两类人 | 并列比较、镜像布局、A/B 结构 |
| 从问题到结果 | 流程、因果链、状态转换 |
| 层级和优先级 | 尺度、阶梯、嵌套层级 |
| 错误和风险 | 警示行、反例、断裂结构 |
| 真实产品和界面 | 用户截图、界面证据、前后对比 |
| 抽象观点 | 文字层级、功能性图形、语义节点 |

抽象观点不必强行配图库人物或 AI 机器人。功能性排版比无关图片更能保留观点。
