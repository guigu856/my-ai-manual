# X/Twitter 平台约束

本文件基线参考 `blog-to-twitter-post`（content-repurposing-skills，最后手动核验 2026-06-07）整理。易变参数写作时按 X 官方资料刷新。

## 稳定特征

- 单条推文一条只讲一个核心观点
- 开头一句可独立理解，不依赖外部上下文
- 0-2 个话题标签
- 不在一开始 @ 用户名（除非有意控制分发）
- 避免互动乞讨；用有用的提问或具体的回应邀请替代
- 有数据保留数据的条件和范围；没数据不制造像数据的说法

## 易变参数（需刷新）

- 字符上限：X 使用加权计数，CJK 字符和 emoji 权重高于拉丁字符；精确长度以官方计数工具为准
- 长推文（Premium）与媒体规格：以写作时的官方说明为准

## Thread 结构

```text
第 1 条：Hook，制造好奇缺口，可独立理解，承诺被后续兑现
中间条：每条一个完整语义单元，单条可被单独转发理解
最后一条：结论 + 具体回应邀请
```

## 写作时默认

- 不用话题标签堆关键词
- 不把历史字符数写死：写出草稿后按当前官方计数核验
- 来源引用明确，不把转述说成原话
