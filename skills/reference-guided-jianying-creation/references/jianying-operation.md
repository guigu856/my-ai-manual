# 操作剪映

## 操作入口

使用宿主提供的 Windows 电脑操作能力。开始前读取 `computer-use:computer-use` 的完整说明，以及它要求的 guidance、API 和 confirmations 文档。

剪映是可见界面操作目标。不要读取或改写内部草稿数据库、加密文件和缓存来代替界面操作。

## 执行前检查

1. 确认当前控制的是剪映窗口；
2. 观察已有项目，避免覆盖其他草稿；
3. 确认创建或打开的项目名称；
4. 设置方案要求的比例、分辨率和帧率；
5. 确认素材目录和逐镜表仍然可读；
6. 记录开始执行时的界面状态。

## 分组执行

按以下顺序分组完成：

1. 导入并整理媒体；
2. 主轨粗剪；
3. 主轨精确时长和速度；
4. BGM、音效和音量；
5. 画中画和其他图层；
6. 字幕和文字；
7. 动画、转场、效果和颜色；
8. 全时间线核对。

每组完成后重新观察时间线和预览窗口。一次只执行当前可确认的操作，界面变化后再定位下一控件。

## 中断和差异

- 剪映窗口关闭、弹窗遮挡或用户接管时，先重新识别当前状态；
- 当前版本没有逐镜表中的功能时，说明差异并提出最接近的基础操作组合，获得确认后再调整；
- 素材缺失、损坏或路径改变时回到素材阶段；
- 记录已经完成的镜头和下一步，支持从中断位置继续。
