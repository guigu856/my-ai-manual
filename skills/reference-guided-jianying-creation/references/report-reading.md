# 阅读参考报告

## 目标

从任意结构的报告或分析文字中理解对新视频有用的制作思路，而不是验证报告格式或重新研究参考视频。

## 阅读方法

先完整阅读，再用自己的话整理：

- 视频怎样吸引观众；
- 内容如何从开头发展到结尾；
- 镜头快慢和画面密度怎样变化；
- 音乐、音效和画面怎样配合；
- 素材、文字、动画和转场怎样组织；
- 哪些做法适合迁移到新主题。

报告只讲到其中一部分时，就使用已经提供的信息。不要因为缺少固定章节而拒绝继续，也不要补写报告没有表达的事实。

## 输出方式

把有用方法自然融入创作方案。无需建立章节、时间点或证据编号映射，也无需机械列出“保留、调整、排除”。

避免照搬原片人物、品牌、素材文件、台词和专属视觉身份。参考的是制作方法和观看感受，新视频使用新的内容与素材。
