# 剪映预览检查

## 完整播放

从时间线开头播放到结尾，至少检查：

- 是否存在黑帧、空轨或意外停顿；
- 素材是否放错、截错或重复；
- 镜头长度和节奏是否符合逐镜表；
- BGM、音效和必要人声是否正常；
- 字幕和文字是否完整、可读且没有挡住主体；
- 画中画、动画、转场和效果是否在正确区间；
- 结尾是否完整结束。

## 修正

发现问题时先定位时间范围，修正后重新播放该区间。涉及整体节奏或声音的问题需要再次从头播放。

## 结束状态

完成后保持：

- 剪映项目处于打开状态；
- 时间线内容完整；
- 预览窗口可以继续播放；
- 播放头位于开头或用户指定位置；
- 导出窗口没有打开；
- 没有执行发布动作。

向用户报告项目名称、目标时长、比例、已完成内容和仍需用户亲自决定的事项。
