# 生成新视频创作方案

## 用户已有主题

把用户表达整理为：

- 核心内容；
- 目标观众；
- 发布平台；
- 画面比例和目标时长；
- 必须出现的内容；
- 明确不使用的内容。

缺少但会直接改变视频结构的信息，只问最关键的一项。

## 用户没有主题

根据参考材料提出三个差异明确的方向。每个方向包含：

```text
主题
主要内容
为什么适合这份参考材料的制作方法
大致需要哪些素材
制作难度：低 / 中 / 高
预期观看感受
```

三个方向应当在内容或受众上真正不同，避免只替换标题。

## 方案要求

方案说明新视频如何组织，而不是大段复述参考报告。至少确定：

- 开头怎样让观众进入；
- 中间怎样推进信息或情绪；
- 最强的一段放在哪里；
- 结尾怎样结束；
- 画面、文字和声音分别承担什么作用；
- 预计需要哪些类型的素材。
