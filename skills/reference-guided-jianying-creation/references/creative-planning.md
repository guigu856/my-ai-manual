# 生成新视频创作方案

## 用户已有主题

把用户表达整理为：

- 核心内容；
- 目标观众；
- 发布平台；
- 画面比例和目标时长；
- 必须出现的内容；
- 明确不使用的内容。

缺少但会直接改变视频结构的信息，只问最关键的一项。

## 用户没有主题

根据参考材料提出三个差异明确的方向。每个方向包含：

```text
主题
主要内容
为什么适合这份参考材料的制作方法
大致需要哪些素材
制作难度：低 / 中 / 高
预期观看感受
```

三个方向应当在内容或受众上真正不同，避免只替换标题。

## 方案要求

方案说明新视频准备怎么做，而不是大段复述参考报告，也不是写“第一段讲什么、第二段讲什么”的叙事段落。至少确定：

1. 视频类型与核心机制——新视频是什么类型（知识讲解、高燃混剪、世界观拼贴等），它依靠什么机制成立、观众为什么看下去；
2. 整体制作方法——这类视频从整体上如何被制作出来：主要剪辑单位是什么、镜头时长如何变化、画面密度如何推进、强拍和细节拍怎么使用、结尾如何收束；
3. 视觉语言——色彩、影调、构图风格如何统一，有哪些贯穿全片的视觉处理；
4. 节奏与声音方法——音乐强弱与画面变化数量、镜头快慢的关系，整体节奏如何安排；
5. 转场与连接的总体原则——画面之间主要用什么方式连接，遵循什么原则；
6. 素材与音乐的总体性质——画面素材大致具有什么性质（实拍、动画、图片、UI 等），BGM 具有什么气质和节奏特征；
7. 预期观看体验——观众从头到尾产生什么感受变化。

参考报告中的方法可以重新组织和改写，不要求标注来自哪一章、哪个时间点或哪条证据。

## 方案不提前决定

方案只确定方向和方法，不提前决定：

- 使用哪个具体素材文件；
- 某个画面必须出现在第几秒；
- BGM 必须在哪一秒变化；
- 视频必须包含多少个镜头；
- 图层坐标、缩放和关键帧；
- 某个镜头的精确持续时间。

这些内容留到素材和逐镜表阶段完成。
