# 参考报告驱动的剪映创作 Skill 设计

## 1. 定位

`reference-guided-jianying-creation` 把一份已有的视频参考报告或分析文字，转化为新视频方案、素材包、逐镜剪辑表，以及剪映中已经完成并可完整预览的时间线。

Skill 只读取参考报告，不下载、抽帧或重新分析参考视频，也不调用 `video-reference-breakdown`。报告只是创作参考材料，不是固定格式的机器合同。

## 2. 输入

### 2.1 参考材料

接受当前对话或本地文件中的：

- DOCX；
- PDF；
- Markdown；
- TXT；
- 用户粘贴的分析文字；
- 其他工具生成的视频分析报告；
- 人工整理的视频制作笔记。

报告不要求固定标题、章节数量、时间线或证据编号。Agent 读取全文，理解其中对新视频有用的制作思路。

### 2.2 新视频主题

用户已经给出主题时直接使用。用户没有给出主题时，Agent 根据报告提出三个差异明确的新视频方向，说明内容、所需素材、制作难度和预期观看感受，等待用户选择。

## 3. 总流程

```text
读取任意参考报告或分析文字
→ 理解可利用的制作思路
→ 取得或提出新视频主题
→ 生成新视频创作方案
→ 用户确认方案
→ 主动搜索、下载并整理素材和 BGM
→ 用户确认素材与 BGM
→ 生成逐镜剪辑表
→ 用户确认逐镜剪辑表
→ 检查本机剪映和项目状态
→ 根据逐镜表操作剪映
→ 完整播放检查
→ 停留在剪映预览状态
```

## 4. 三个确认点

只保留会改变后续执行的确认：

1. 确认新视频创作方案；
2. 确认最终素材和 BGM；
3. 确认逐镜剪辑表，然后开始操作剪映。

确认后的内容作为后续阶段输入。发现新问题时回到对应确认点修正，不在剪映执行期间临时改变主题、素材或镜头结构。

## 5. 阶段产物

### 5.1 创作方案

创作方案使用普通中文说明：

- 视频主题与目标观众；
- 发布平台、比例和目标时长；
- 内容结构；
- 整体观看感受；
- 准备采用的制作思路；
- 画面、文字和声音方向；
- 所需素材类别。

参考报告中的方法可以重新组织和改写，不要求标注来自哪一章、哪个时间点或哪条证据。

### 5.2 素材和 BGM

Agent 根据确认后的方案主动完成：

- 列出素材需求；
- 搜索候选素材；
- 下载并检查文件；
- 选择可用区间；
- 做必要的裁切、转码和尺寸整理；
- 搜索或选择 BGM；
- 整理素材预览、来源和本地路径。

最终素材确认后，后续逐镜表只使用已确认文件。

### 5.3 逐镜剪辑表

逐镜表只保留剪映执行需要的信息：

| 时间 | 使用素材 | 画面怎么处理 | 文字 | 声音 | 衔接方式 |
| :-- | :-- | :-- | :-- | :-- | :-- |

复杂镜头可以补充轨道、素材截取区间、速度、画中画、动画、效果和音量。表格需要连续覆盖整条新视频，并让另一个 Agent 只读表格也能执行。

## 6. 剪映执行

Skill 使用宿主的 Windows 电脑操作能力控制剪映，不直接修改剪映草稿文件，也不调用项目内的剪辑组件或渲染程序。

执行顺序：

1. 检查剪映窗口、当前项目和素材路径；
2. 创建或打开目标项目；
3. 导入素材和 BGM；
4. 搭建主轨并确定镜头时长；
5. 添加声音、文字、画中画、动画、转场和效果；
6. 对照逐镜表检查全部镜头；
7. 从头完整播放预览；
8. 修正发现的问题；
9. 停留在可再次播放的预览状态。

每完成一组镜头就核对剪映当前画面和时间线状态。界面与预期不同时先重新观察，再决定下一步，不连续盲点坐标。

## 7. 结束边界

完成条件：

- 素材已经进入剪映项目；
- 时间线连续且没有计划外空档；
- 逐镜表中的镜头、文字和声音已经落实；
- 已经从头完整播放检查；
- 剪映停留在完成时间线的预览状态。

Skill 不点击最终导出，不发布视频，也不把剪映时间线转换为项目内的 `EditorProject` 或其他渲染工程。

## 9. 验收标准

- 任意结构的参考报告都可以进入创作流程；
- 缺少参考报告时只请求报告，不启动参考视频拆解；
- 缺少新主题时提供三个方向供用户选择；
- 创作方案、素材和逐镜表分别经过确认；
- Agent 主动搜索、下载、检查和整理素材与 BGM；
- 逐镜表连续覆盖新视频并包含剪映执行所需信息；
- 剪映操作只走可见界面；
- 完成后停留在完整预览状态，不点击导出；
- 只要求拆解参考视频、审查已有成片或导出视频时不触发本 Skill。
- Skill 合同测试和 `quick_validate.py` 通过。
