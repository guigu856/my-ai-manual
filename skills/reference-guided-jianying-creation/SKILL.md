# 参考报告驱动的剪映创作

## 目标

把任意格式的参考报告或分析文字转化为：

1. 一份新视频创作方案；
2. 一组已经确认的素材和 BGM；
3. 一份连续可执行的逐镜剪辑表；
4. 剪映中已经完成并经过完整播放检查的时间线。

最终停留在剪映预览状态。不要点击导出。

## 输入边界

接受 DOCX、PDF、Markdown、TXT、聊天中粘贴的分析文字，以及其他工具生成的报告或人工笔记。报告不要求固定标题、章节数量、时间线或证据编号。

缺少参考报告或分析文字时，只请求用户提供参考材料。不要调用 `video-reference-breakdown`，不要下载、抽帧或重新分析参考视频。

## 输出目录

在当前项目工作区建立：

```text
output/reference-guided-jianying-creation/<run-id>/
```

保存创作方案、素材、BGM、逐镜表和执行记录。不要把任务产物写入 Skill 安装目录。

## 执行流程

### 1. 阅读参考材料

读取全部报告或分析文字。DOCX 使用文档读取能力，PDF 使用 PDF 读取能力，文本文件直接读取。

读 `references/report-reading.md`，理解报告中对新创作有用的内容。把它当作创作参考，不要求证明某个方法来自哪一章、哪个时间点或哪条证据。

### 2. 确定新视频主题

- 用户已经给出主题：整理目标观众、平台、比例、时长和内容限制。
- 用户没有给出主题：根据参考材料提出三个差异明确的方向，写清内容、所需素材、制作难度和观看感受，等待用户选择。

### 3. 生成并确认创作方案

读 `references/creative-planning.md`，按照 `templates/creative-plan.md` 生成方案。方案重点写新视频准备怎么做，不复述整份参考报告。

向用户展示完整方案并等待确认。这是第一个确认点。收到修改意见时先更新方案，再进入素材阶段。

### 4. 主动准备素材和 BGM

读 `references/material-preparation.md`，根据已确认方案：

1. 列出素材需求；
2. 主动搜索候选素材；
3. 下载并检查文件；
4. 选择可用区间；
5. 做必要的裁切、转码和尺寸整理；
6. 搜索或选择 BGM；
7. 整理预览、来源和本地路径。

向用户展示最终候选素材与 BGM，等待确认。这是第二个确认点。后续逐镜表只使用已确认文件。

### 5. 生成并确认逐镜剪辑表

读 `references/shot-table.md`，按照 `templates/shot-table.md` 编写连续覆盖新视频的逐镜表。

逐镜表至少写清：

```text
时间
使用素材
画面怎么处理
文字
声音
衔接方式
```

复杂镜头补充轨道、素材截取区间、速度、画中画、动画、效果和音量。另一个 Agent 只读取逐镜表也应当能完成剪辑。

展示完整逐镜表并等待确认。这是第三个确认点。确认后再控制剪映。

### 6. 准备操作剪映

使用 `computer-use:computer-use`。在首次控制 Windows 应用前，完整读取该 Skill 及其要求的 guidance、API 和 confirmations 文档。

读 `references/jianying-operation.md`，检查：

- 剪映窗口和当前项目状态；
- 新建还是打开目标项目；
- 项目比例、分辨率和帧率；
- 素材与 BGM 路径；
- 当前剪映版本中的可用功能。

只通过可见界面操作剪映。不要直接修改剪映草稿文件，不要调用项目内的剪辑组件或渲染程序。

### 7. 完成剪映时间线

按照逐镜表分组执行：

1. 创建或打开项目；
2. 导入素材和 BGM；
3. 搭建主轨并调整镜头时长；
4. 添加声音、文字和画中画；
5. 添加动画、转场和效果；
6. 调整速度、音量和画面参数；
7. 对照逐镜表检查全部镜头。

每完成一组镜头就重新观察剪映窗口和时间线，再继续下一组。界面与预期不同时先检查当前状态，不连续盲点坐标。

操作中断时，记录已完成镜头、当前时间线位置、发现的问题和下一步，不把未完成时间线描述为已经完成。

### 8. 完整预览并结束

读 `references/preview-check.md`，从头播放完整时间线，检查画面、声音、文字和镜头衔接。发现问题时回到时间线修正并重新播放相关区间。

全部检查完成后：

- 保持剪映项目打开；
- 把播放头放在适合再次预览的位置；
- 停留在可播放的预览状态；
- 向用户说明项目状态和已完成内容；
- 不点击最终导出。

## 三个确认点

严格保留：

1. 创作方案确认；
2. 素材与 BGM 确认；
3. 逐镜剪辑表确认。

确认后再进入下一阶段。剪映执行期间不临时改变主题、素材或镜头结构；确需修改时回到对应确认点。

## 边界

- 本 Skill 读取参考报告，不执行参考视频拆解。
- 报告是创作参考，不是固定结构合同。
- 本 Skill 主动搜索和整理新视频素材及 BGM。
- 本 Skill 操作本机剪映，不生成 `EditorProject` 或程序化渲染工程。
- 本 Skill 完成时间线和预览检查，不执行最终导出或发布。
- 用户只要求审查已有成片时，使用成片审查 Skill。
