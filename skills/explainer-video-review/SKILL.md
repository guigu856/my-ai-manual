# 概念动效视频成片审查

## 审查输入与操作方式

1. 收齐三样：成片 mp4、冻结文稿（字幕/内容对位基准）、制作要求（若有）。先通读文稿，标出段落边界和所有枚举清单（几项、什么顺序、什么用词）。这些信息有则从上下文获取；文稿没有明确内容时，再从视频提取。
2. 抽帧：默认抽帧粒度为 1s/帧。动效密集或转场段落可加密到 0.5s/帧或更高频率。抽帧参数须在审查开始前由 agent 与用户确认，也可拼 N×N 接触表快速浏览。
3. 长片分段并行审查：每段独立过四个维度，最后汇编去重。
4. 声音必须听：音画同步类问题要配合对应段落的音频核对。
5. 客观指标先检查：视频帧数与时长的匹配度、音频质量、配音音色。
6. 输出纪律：直接出问题清单，避免泛泛表扬。

## 审查流程

1. 审查前先与用户确认抽帧频率。
2. 按四个维度逐步审查，完成后在聊天上下文直接输出问题清单。
3. 一个维度为一个单元任务，一次单元任务为一次输出结果；用户确认修改项后，进行修改完成此维度，确认完成后再进行下一维度。
4. 报告可按长度直接输出或写成 Markdown 文档。
5. 每个维度单元可以规划子 agent 完成后汇总，也可以由当前 agent 独立完成。

## 四个审查维度

1. [视觉表达与信息聚焦](resources/visual-expression.md)
2. [空间一致与动效连贯](resources/spatial-continuity.md)
3. [时序对齐精度](resources/temporal-alignment.md)
4. [字幕规范与可读性](resources/subtitle-readability.md)

## 输出格式

示例：

```text
【维度】 编号 | 时间戳 | 问题描述 | 严重级 | 修复建议
```

修复建议要具体到“改什么、改成什么”，避免空泛意见。

分析完成后删除本次产生的临时工作文件（抽帧图片、音频片段等）。

## 生产交接

审查发现的问题回到 `../script-to-explainer-video/SKILL.md` 处理源文件和时间轴；修复完成后重新渲染，再回到对应维度复查。
