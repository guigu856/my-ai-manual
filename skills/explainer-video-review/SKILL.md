# 概念动效视频成片审查

## 审查输入与操作方式

1. 收齐三样：成片 mp4、冻结文稿（字幕/内容对位基准）、制作要求（若有）。先通读文稿，标出段落边界和所有枚举清单（几项、什么顺序、什么用词[...]）
2. 抽帧：默认抽帧粒度为 1s/帧。动效密集或转场段落可加密到 0.5s/帧 或更高频率。抽帧参数须在审查开始前由 agent 与用户确认（见下文）。也可拼 N×N 接触表快速浏览。
3. 长片分段并行审查：每段独立过四个维度，最后汇编去重。
4. 声音必须听：音画同步类问题只看帧查不出来，抽帧段落要配合该段音频核对。
5. 客观指标先跑一遍：`ffprobe` 帧数 = 时长×fps；全解码 `ffmpeg -v error -i in.mp4 -f null -` 无报错；响度 ≈ -16 LUFS（±1）。配音音色听一遍：有机器人音/电流噪声需记录。
6. 输出纪律：不许泛泛表扬，直接出问题清单。

## 审查流程（按维度逐步执行）

为保证 agent 每次审查都按维度分步执行（而非先整体观看再归类），在此明确必须遵循的执行顺序与交付格式：

0) 审查前的确认（必须步骤）
   - 在任何抽帧或生成工件之前，agent 必须向用户确认抽帧间隔（秒/帧）：例如输入形式为 `1s`、`2s`、`0.5s` 或 `自动`（自动表示 agent 根据场景密集度在动效密集区段自动加密抽帧）。
   - 若用户未明确指定，agent 应默认使用 1s/帧，并在所有产物头部注明“使用默认抽帧间隔 1s/帧”。
   - agent 必须把用户确认的抽帧参数记录在 per-segment metadata 中（meta/），并在提交的每个维度清单头部写明所用抽帧参数与抽音参数。

1) 划分片段与准备工件：
   - 将成片按时间分为 N 段（4–6 段或按项目要求），为每段生成抽帧与对应音频片段（按用户确认的抽帧粒度生成帧图片序列）。
   - 为每段准备：frames/（帧图片序列）、audio/（段落音频）、script/（该段冻结文稿及枚举清单）、meta/（制作要求与抽帧参数）。

2) 对每一段，按下面严格顺序逐维度审查并输出该段的维度报告（不得跨维度混合描述）：
   - 维度一（视觉表达与信息聚焦）→ 完成后立即保存该维度的发现清单（见输出格式）
   - 维度二（空间一致与动效连贯）→ 完成后保存该维度的发现清单
   - 维度三（时序对齐精度）→ 完成后保存该维度的发现清单（务必对齐音轨）
   - 维度四（字幕规范与可读性）→ 完成后保存该维度的发现清单（务必与配音逐字核对）

   要求细则：
   - 对每个维度，审查内容应包含：问题编号、时间戳（帧或时间范围）、问题描述、严重级、修复建议（具体可操作）。格式严格为：
     `编号 | 时间戳(范围) | 问题描述 | 严重级 | 修复建议`
   - 每个维度的发现以该段为单位输出一个小清单（例如：segment-01.dim1.md、segment-01.dim2.md 等），命名须包含段号与维度编号。
   - 在单维度内可使用抽帧截图（附带帧号）和音频时间点作为证据，但不得把跨维度的评论写入该维度清单（例如：在“字幕”清单中不要写“元素位置漂移”，应在“空间一致”清单中说明）。
   - 每项问题应尽量精确到帧或毫秒（例如：00:01:23.400–00:01:24.200 或 f_0034–f_0037），并且给出明确修复方案（改成什么、什么时候、如何改）。

3) 段内去重与合并：
   - 在完成该段四个维度的独立清单后，执行去重——若同一现象同时出现于两维度的记录（真实语义重合），保留最精确的一项并在另一项中引用编号。禁止在此阶段合并为“模糊”的跨维度条目。
   - 生成该段的汇总清单（segment-01.summary.md），结构按照阻断→明显→轻微排序，每项保持原始维度标记（例如：[维度2]）。

4) 全片汇编与优先级整理：
   - 将所有段的汇总清单合并为全片报告；合并时按时间先后、严重级与维度分组，移除重复条目并保留首次出现的时间戳。
   - 输出三梯队修复优先级（同文档原有规则）：第一梯队（阻断）、第二梯队（明显）、第三梯队（轻微），并在每个梯队内按时间排序以便制作方逐段修复。

5) 产物与交付：
   - 提交文件（至少）：
     - per-segment per-dimension 原始发现文件（segment-XX.dimY.md）
     - per-segment 汇总（segment-XX.summary.md）
     - 全片合并报告（full-report.md）
     - 附证截图与音频片段（evidence/目录，文件名对应问题编号）
   - 每个文件头部须写明 reviewer（agent 名）、审查时间、使用的抽帧与抽音参数。

6) 质量要求与治理：
   - Agent 严禁先通片后把问题随机贴到维度下；必须按本流程严格“逐段逐维度”完成并先输出各维度清单。
   - 如发现 agent 未遵守此流程，审查输出应被标记为“流程不合规”，并要求重新按步骤执行。

## 维度一：视觉表达与信息聚焦

审查对象（抽象维度）：**每一帧的画面元素与动效设计是否服务于核心观点的突出表达**——信息焦点是否明确、视觉形式是否克制且有意义。

一句话判据：任意帧暂停，观众能否在 1 秒内说出"这一帧想让我理解什么"。

### 1.1 核心观点突出度

- 画面设计是否真的在围绕此处想表达的观点在设计
- 整体元素组合是否符合当前语境：是否起到核心观点显化性
- 画面设计是否起到能帮助用户理解核心观点的辅助性作用
- 主体元素占比是否足够：画面不空旷、元素不显小；用约 360px 宽度模拟手机小屏，标题/节点/标签仍可辨认。
- 有无与表达无关的元素：装饰填充、栏目名、状态信息、编号、版本、数据、英文小字、伪 UI、品牌 logo 充当通用图标。
- 元素重复：同一概念是否两处呈现（既做独立节点又出现在容器列项里）。

### 1.2 文字与标题设计

- 画面文字是否只留核心标题、短判断、模块名；有无描述性副文本小字（尤其与字幕内容重复的）。
- 标题是否只做短点题（点题词或模块名），有无变成长句复述字幕。
- 标题与字幕是否同屏同义复读（上下各说一遍同一句话）。
- 有无大段文字朗读倾向：完整内容应由配音讲解，画面出现供阅读的长文本即记录。
- 标题或者文字有无起到突出核心观点的作用，或者让用户一看就知道你这里要讲的什么的作用
- 模块名用词与配音是否逐字对应；全片同一术语是否统一（不得前文"脚本"结尾变"模板"）；标点全半角是否统一。

### 1.3 动效语义合理性

- 动效是否在传达概念（方向、变化、关系本身有意义），还是为了动而动。
- 枚举项出现顺序、数量与文稿是否一一对应：不多出文稿没有的项（配音未念出的概念混入枚举要记录）。
- 枚举标注完整性：该段配音结束时所有项的标注是否全部到位，缺项按阻断记录。
- 图标/图形语义是否准确（如"外部软件"用了不相关的品牌图形）。

## 维度二：空间一致与动效连贯

审查对象（抽象维度）：**元素之间的位置、轨迹、进出场关系在全过程中是否保持秩序**——不只看某帧整齐，而是出现、移动、重组、离开、转场全流程一致。

一句话判据：从头到尾连续播放，有没有任何一帧让你"跳戏"。

### 2.1 位置与对齐

- 元素是否按锚点/网格对齐：有无位置漂移、线条偏移、连线错位（线的端点与元素边缘脱开）。
- 文字之间、文字与图形之间有无重叠、遮挡、裁切、出画。
- 数量帧间一致性：同类元素（圆点、节点）数量在相邻帧间是否稳定，6/7/8 跳动记为漂移/闪烁。
- 父子元素是否联动：标题与其所属图形、容器与其内容物是否作为一组同进同出、同步移动。

### 2.2 运动轨迹连贯性

- 相邻帧间元素有无位置跳变（应连续位移却瞬移）。
- 每个动画是否有明确起点和落点，中途无抖动、无回拉。
- 运动是否可追踪：快速运动中元素身份不丢失。

### 2.3 进出场与转场

- 元素消失是否有过渡（收缩/淡出 ≥0.5s）：一帧内从满屏信息变空白 = 断崖消失，按阻断记录。
- 转场是否为元素重组（前场元素变形/移动/融入后场）：**整场硬切（元素全消失+新场景瞬现）逐处记录**。
- 上一场景残留：新段落配音开始后画面仍停留上一段内容 >1s。
- 过渡帧新旧共存打架：旧元素未清场就叠加新元素。
- 多元素变化是否拆拍完成：标题+字幕+图形同帧瞬变记为无过渡。
- 鬼影与残影：进度为 0 的线渲染成孤点、父级 scale=0 时子元素提前显形、结尾帧残留低透明度元素或错字。
- 两条线经过同一区域是否打架（应共用同一直线、前淡出后绘入）。

## 维度三：时序对齐精度

审查对象（抽象维度）：**声音、动效、字幕三条轨道是否以配音为基准精确同步**——听到什么，同时看到什么。

一句话判据：闭眼听 → 睁眼看，画面展现的内容是否恰好是听到的。

### 3.1 配音与整体对位

- 第一帧与首段配音起点对齐；段间间隔均匀（约 0.3–0.5s，全片一致）。
- 画面段落切换点 ≤ 配音新段落起点（画面可以略提前，不允许滞后开讲还在旧画面）。

### 3.2 动效节拍与配音同步

- 枚举逐项出现节奏跟随配音（每项间隔以配音中该词所在 cue 的实际时间为准，容差 ±5 帧/约 150ms）：
  - **抢跑**：配音要念 5–6s 的枚举，画面 2s 铺完然后静止等配音——按阻断记录。
  - **滞后**：配音已念到某项，对应元素迟迟未出；或段落开始数秒仍是上一段画面。
- 图标/标签出现时机与字幕、配音同帧或略提前 ≤0.5s；先出空框后补文字记为不同步。
- 标题切换点对齐配音说到该内容的时刻：提前剧透结论（配音还没说标题先亮）或滞后都要记录。

### 3.3 字幕与配音对位

- 字幕出现帧 = 句级 cue ±1 帧。
- **字幕文本必须是配音逐字原文**：随机抽 5–8 个时间点逐字核对；改写、加词（配音没有的"例如，"出现在字幕）、枚举被扩写成同义长句（配音两句被合并为一条或被拆分）均属错误。
- 字幕切换跟随配音：念完的句停留 >1.5s 记为滞后。

## 维度四：字幕规范与可读性

审查对象（抽象维度）：**字幕作为独立阅读通道是否规范、连续、完整、可读**——它是听障/静音场景下唯一的信息通道。

一句话判据：关掉声音只看字幕，能否顺畅读完并完全理解。

### 4.1 标点与文本

- 句末无标点：句号、问号、感叹号一律不得出现。
- 全片标点全半角统一（全角）。
- 字幕文本与配音逐字一致（与维度三 3.3 交叉验证）。

### 4.2 时序连续与完整性

- **无断层**：字幕连续覆盖全片，段间间隔也要有覆盖；转场处不得出现无字幕真空。
- **句子完整**：单条字幕语义完整，完整意群不得截断到两条；双音节词不得跨条拆开（如"项目状|态"按阻断记录）。
- 切换节奏：一条字幕不得停留过久，也不得早于配音消失。

### 4.3 版面与长度

- **只允许一行**：出现两行即记录（长句应在逗号/顿号处切分为多条，或缩字号）。
- 单条不超画布一行容量；超宽文字被裁切/溢出画面按阻断记录。
- 小屏可读性：字幕字号在手机尺寸下清晰可辨。

## 严重级定义

- **阻断**：破坏信息传达或违反制作红线——字幕与配音脱节/改写、核心枚举缺项、整场硬切、文字截断溢出、画面与文稿段落错位、结尾残影错字、关键元素漏标等。
- **明显**：影响观感与节奏——标题时序（剧透/挂太久/复读）、卡片化形态、元素过载、长静止段、新旧画面残留打架、同概念重复呈现。
- **轻微**：打磨项——标点全半角、模块名用词微差、微节奏（±0.5s 内）、过渡帧辨识度。

## 输出格式

每条问题：`编号 | 时间戳(范围) | 问题描述 | 严重级 | 修复建议`，按 阻断 → 明显 → 轻微 汇编，结尾给三梯队修复优先级：

1. 第一梯队（阻断）：逐条列出，先改。
2. 第二梯队（明显）：按类型归并（时序类/风格类/构图类）。
3. 第三梯队（轻微）：打磨项打包。

修复建议要具体到"改什么、改成什么"（如：字幕回归配音原文；5 个标注压缩到某区间均匀分布；标题切换移到配音某句处），不写空泛意见。
