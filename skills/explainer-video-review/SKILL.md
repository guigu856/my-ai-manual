# 概念动效视频成片审查

## 适用范围

这个 Skill 只审查已经渲染出来的成片。它负责发现问题、记录时间点和给出修复方向；源文件修改、重新渲染和最终交付仍回到生产流程。

## 输入

- 成片 MP4
- 冻结文稿、字幕或 `segments.json`（有则使用）
- `timeline.json`、最终配音和制作要求（有则用于对位）

缺少基准材料时，按视频本身做可观察审查，并在报告里说明依据范围。

## 审查流程

1. 先通读文稿和制作要求，找出段落边界、核心观点和枚举项。
2. 先完整浏览成片，再抽帧检查。默认约 1 秒一帧；快速动效、复杂转场或音画争议段落加密到 0.5 秒或更密。
3. 音画同步问题必须配合听音频，不能只看画面判断。
4. 依次读取下面四个 resources 文件，逐项检查并记录时间戳。
5. 一次输出完整的问题清单；长片可以按维度分段分析，最后合并去重。
6. 发现源文件问题后，回到生产 Skill 修复，整片重新渲染，再审查新版本。

## 四个审查维度

1. [视觉表达与信息聚焦](resources/visual-expression.md)
2. [空间一致与动效连贯](resources/spatial-continuity.md)
3. [时序对齐精度](resources/temporal-alignment.md)
4. [字幕规范与可读性](resources/subtitle-readability.md)

## 输出格式

直接输出具体问题，不写泛泛表扬：

```text
【维度】问题编号 | 时间戳 | 问题描述 | 严重级 | 修复建议
```

修复建议要落到“改哪个元素、改哪个时间点、改成什么效果”。没有足够依据的判断标成“待确认”。

## 生产交接

审查 Skill 的结果交给 `../script-to-explainer-video/SKILL.md` 处理源文件、cue、时间轴和重渲染；审查本身保持只读，避免同时维护两套制作规则。
