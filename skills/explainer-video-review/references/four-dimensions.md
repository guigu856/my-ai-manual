# 四维检查规则

每个检查项都要绑定到审查基准和证据类型。检查结果可以在一次完整审查中汇总输出；维度不是必须暂停等待用户确认的交互关卡。

## 1. 视觉表达与信息聚焦

判据：暂停任意关键帧，观众能在约 1 秒内说出这一帧要表达的核心内容。

### 核心观点

- 主体是否围绕当前段落的观点服务，而非堆放装饰、编号、版本、品牌或无关状态信息
- 主体在约 360px 宽等效画布下是否仍可辨认
- 同一概念是否被重复成独立节点、容器条目和字幕之外的第三层表达
- 画面元素是否帮助理解关系、变化、方向、层级或因果

### 文字与术语

- 标题是否是短点题词、模块名或判断，而非复述整句字幕
- 描述性副文本、小字和字幕是否形成同义重复
- 画面文字是否出现大段朗读倾向
- 模块名、字幕、配音中的核心术语是否统一

### 动效语义与枚举

- 动效是否表达概念关系，而非单纯为了运动
- 枚举项的数量、顺序、名称和配音是否一致
- 段落结束前，配音提到的项是否全部出现并保持可追踪
- 图标和图形是否与语义相符

证据优先：关键帧、连续帧、冻结文稿、`segments.json`、字幕 cue。

## 2. 空间一致与动效连贯

判据：连续播放时，元素身份、锚点、父子关系和运动轨迹保持可追踪。

### 位置和层级

- 元素是否遵守网格、锚点、安全区和对齐关系
- 文字、图形、连线是否重叠、遮挡、裁切或出画
- 同类节点数量是否在相邻帧间无意变化
- 父元素与子元素是否作为一组进出场

### 运动和转场

- 相邻采样帧是否存在位置跳变、抖动、回拉或失去身份
- 每段运动是否有清楚的起点和落点
- 元素消失是否有合理过渡；满屏内容瞬间清空需要记录为风险
- 转场是否是元素重组，而非整场消失后新场景瞬现
- 新段落开始后是否仍停留上一段内容超过约 1s
- 过渡帧中新旧内容是否互相遮挡或语义冲突
- 进度为 0 的线、父级 scale 为 0 的子元素、残影和重叠连线是否出现异常

证据优先：连续帧、转场前后帧、时间轴段边界、场景状态数据。

## 3. 时序对齐精度

判据：闭眼听到的内容与睁眼看到的画面、字幕和动效处于同一语义窗口。

### 配音与整体对位

- 首帧、首段配音和首条字幕是否对齐
- 画面段落切换是否早于或紧跟新段配音起点
- 段间停顿和尾部留白是否符合制作要求

### 动效节拍

- 枚举项是否跟随配音逐项出现
- 画面是否过早铺完后静止等待配音
- 配音已说到某项时，对应元素是否迟到
- 图标、标签、标题和字幕是否在语义 cue 附近出现
- 空框先出现、文字后补或转场提前发生是否造成理解错位

### 字幕对位

- 字幕起止时间是否与句级 cue 相符
- 字幕文本是否与配音逐字一致；差异是否属于明确的标点/口语策略
- 字幕切换是否截断意群或晚于声音窗口

证据要求：画面证据 + 音频窗口；存在时间轴时再引用 `timeline.json`。

## 4. 字幕规范与可读性

判据：静音观看时，字幕能够连续、完整、清晰地传达内容。

### 文本

- 句末标点和全片标点风格是否统一
- 字幕文本、冻结文稿和配音是否逐字一致或有记录的差异
- 同一术语、专名和数字格式是否统一

### 覆盖与分句

- 字幕是否覆盖有效配音区间，转场处是否出现真空
- 意群是否被截断，双音节词或固定短语是否被拆开
- 切换节奏是否允许完整阅读

### 版面

- 单条字幕是否保持一行或符合明确的多行规则
- 字幕是否超出安全区、被裁切、遮挡画面重点或与画面文字打架
- 约 360px 宽等效预览下，字号和对比度是否可读

证据优先：字幕文件、字幕帧、手机尺寸预览、音频窗口和安全区要求。

## 5. 技术完整性（跨维度前置检查）

技术检查不替代四个内容维度，但要在报告中单独列出：

- MP4 可读取，时长、帧率、尺寸和编码信息已记录
- 视频和音频流存在且时长关系合理
- 字幕、音频、视频的版本和路径可追溯
- 代表帧与整片来自同一媒体指纹
- 报告中的时间戳均落在媒体有效范围内
