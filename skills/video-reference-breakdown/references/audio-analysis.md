# 声音分析方法

## 分析目标

声音分析服务于“画面为什么在这个时间变化”，不是为了提供一份独立音乐学报告。

## 观察顺序

1. 听完整音轨，确认主要情绪和声音组成。
2. 查看波形和强弱数据，找到段落增强、减弱、停顿和释放候选。
3. 回听候选时间附近的原声音。
4. 对照画面，判断变化发生在声音之前、同时还是之后。
5. 只把影响剪辑和观看感受的声音变化写入报告。

## 需要说明的内容

- 音乐整体情绪；
- 能够分辨的鼓、低频、旋律、人声、环境声和额外音效；
- 声音层何时加入或退出；
- 明显重音、停顿、尾音和段落转折；
- 音乐强弱变化与镜头长度、效果数量的关系。

## 候选纪律

脚本提供的 tempo、重要声音变化和强弱数据是观察线索。以下情况降低把握程度：

- 音乐与对白混在一起；
- 鼓点不清晰；
- 视频经过严重压缩；
- 音效与音乐重音重叠；
- 算法结果与实际听感冲突。

## 五种常见配合

| 配合方式 | 判断方法 | 常见作用 |
| :-- | :-- | :-- |
| 同时发生 | 重要声音与切换、放大或文字出现接近同一时间 | 增强力度 |
| 画面提前 | 动作先开始，在声音增强处完成 | 制造期待 |
| 画面稍后释放 | 声音先出现，画面随后完成变化 | 产生落地或爆发感 |
| 持续声音连接 | 画面已切换，上一段声音仍持续 | 减少割裂 |
| 跟随内容而非鼓点 | 画面响应歌词、情绪或音色 | 加强内容联系，避免机械卡点 |

实际时间差用毫秒或秒记录在分析证据中，用户正文优先说明先后关系和观看作用。
