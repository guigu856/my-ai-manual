# 五章报告合同

## 封面与基本信息

标题：

```text
《视频名称》拆解报告
```

副标题：

```text
这条视频好看的原因、它的剪辑方法，以及可以复用到其他视频里的技巧
```

基本信息表：

| 项目 | 内容 |
| :-- | :-- |
| 视频来源 | 文件或原始链接 |
| 视频时长 | `00:00` |
| 画面规格 | 分辨率、横竖屏、帧率 |
| 是否包含音乐 | 是 / 否 |
| 分析范围 | 完整视频 / 指定片段 |
| 分析时间 | `YYYY-MM-DD` |

## 第一章：先用一分钟看懂这条视频

依次写：

1. 这是一条什么视频；
2. 它最主要的一至三个吸引力；
3. 素材、镜头、音乐、文字和效果大致如何组织；
4. 观众感受如何从开头发展到结尾；
5. 一句话总结。

观众感受表：

| 视频阶段 | 观众感受 | 主要原因 |
| :-- | :-- | :-- |

## 第二章：音乐和声音是怎么带动视频的

依次写：

1. 整体听感；
2. 音乐段落；
3. 对剪辑真正重要的声音变化；
4. 音乐从弱到强、停顿、释放和减弱的过程；
5. 音乐强弱与画面变化数量的关系；
6. 本章结论、依据和把握程度。

音乐段落表：

| 时间 | 音乐发生了什么 | 强弱变化 | 画面如何配合 |
| :-- | :-- | :-- | :-- |

声音变化表：

| 时间 | 听到了什么变化 | 画面发生了什么 | 带来的感觉 |
| :-- | :-- | :-- | :-- |

不要机械列出所有鼓点。只保留确实影响段落、动作、切换和观看感受的声音变化。

## 第三章：画面是怎么一段段剪出来的

### 完整画面时间线

| 时间 | 主要画面 | 画面里的变化 | 对应声音 | 产生的作用 |
| :-- | :-- | :-- | :-- | :-- |

时间线从视频开始连续覆盖到结束。片段边界优先取自真实帧时间；算法候选需要由实际画面确认。

### 重点片段

每个值得学习的片段使用：

```text
片段名称
时间
实际看到了什么
画面进行了什么处理
声音如何配合
这种处理带来什么效果
可以学到什么
画面依据
声音依据
把握程度
```

### 反复出现的处理

根据实际视频总结镜头切换、放大缩小、主体移动、字幕、前景遮挡、画中画、颜色亮度、定格、模糊、闪白和局部效果。只写实际出现的处理。

## 第四章：声音和画面是怎么配合的

先解释视频实际使用的配合方式：

- 声音和画面同时发生；
- 画面提前行动；
- 音乐出现后画面再释放；
- 持续的声音连接前后两个画面；
- 画面跟随歌词、情绪或声音质感，而不是机械卡点。

再整理可以重复使用的剪法：

```text
剪法名称
适合什么时候使用
具体怎么剪
能带来什么效果
参考时间
画面依据
声音依据
把握程度
```

剪法名称直接描述动作，例如“相同方向连接”“先慢后快再停一下”“重拍负责冲击、尾音负责连接”。

## 第五章：如果重新做一条，应该学什么

依次写：

1. 最值得保留的观看体验；
2. 可以直接复用的方法，按重要程度排序；
3. 不应照搬的人物、素材、绝对时间点、坐标和效果参数；
4. 使用新素材重新创作的执行顺序；
5. 最终检查表。

最终检查表至少检查：

| 检查项 | 判断 |
| :-- | :-- |
| 开头是否让观众快速知道要看什么 | 是 / 否 |
| 音乐增强时画面是否同步加强 | 是 / 否 |
| 快切是否服务明确的节奏变化 | 是 / 否 |
| 不同场景之间是否存在动作或声音连接 | 是 / 否 |
| 高潮前是否完成足够蓄力 | 是 / 否 |
| 高潮后是否留出缓冲 | 是 / 否 |
| 是否存在只炫技、没有观看作用的效果 | 是 / 否 |
| 新视频是否保留方法而不是照搬原片 | 是 / 否 |
