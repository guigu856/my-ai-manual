# 四部分报告合同

本合同自足描述拆解报告的全部要求。报告正文不得出现内部章节编号、阶段名称或内部分析对象名称。

## 封面与基本信息

标题：

```text
《视频名称》拆解报告
```

副标题：

```text
这条视频好看的原因、它的剪辑方法，以及可以复用到其他视频里的技巧
```

基本信息表：

| 项目 | 内容 |
| :-- | :-- |
| 视频来源 | 文件或原始链接 |
| 视频时长 | `00:00` |
| 画面规格 | 分辨率、横竖屏、帧率 |
| 是否包含音乐 | 是 / 否 |
| 分析范围 | 完整视频 / 指定片段 |
| 分析时间 | `YYYY-MM-DD` |

## 第一部分：这条视频是怎么立起来的

依次写：

1. 这是一条什么视频——先给视频类型，再点出它靠什么成立（核心机制：这种类型为什么成立、它最主要的吸引力由什么产生）；
2. 它大致是怎么做出来的——这类视频从整体上如何被制作出来，写全片主线方法，不写逐镜细节；
3. 它的视觉语言——色彩、影调、构图风格如何统一，有哪些贯穿全片的视觉处理；
4. 节奏与声音的总体方法——音乐强弱与画面变化数量的关系、整体节奏如何安排；
5. 转场与连接的总体原则——画面之间主要用什么方式连接，遵循什么原则；
6. 素材与音乐的总体性质——画面素材和音乐大致具有什么性质，一句话级概括；
7. 观众的感受如何变化——观众感受如何从开头发展到结尾，附一句话总结。

观众感受表：

| 视频阶段 | 观众感受 | 主要原因 |
| :-- | :-- | :-- |

本部分只保留全片主线，不堆叠逐镜细节。

## 第二部分：它用了什么素材和音乐

### 2.1 画面素材盘点

归纳这条视频实际使用的画面素材：

- 素材类型：用了哪些类型的画面（实拍、动画、图片、UI 界面、文字卡、生成画面等），大致出现在哪些区间；
- 景别规律：常用什么景别、景别如何变化；
- 构图规律：主体放在画面什么位置、靠什么引导视线；
- 动作方向规律：主体运动方向如何安排、相邻画面方向是否延续；
- 技术质量：清晰度、噪点、压缩痕迹、调色特征。

## 第三部分：它怎么一段段剪出来的

### 3.1 全片时间线

| 段 | 时间 | 画面构成 | 画面处理 | 附加效果 | 声音与节拍 | 与下一段的衔接 | 把握程度 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- |

列要求：

- 段：段落序号。段落边界是分析判断，不是确定的原片镜头号；
- 时间：该段起止时间，优先取自真实帧时间，算法候选需要由实际画面确认；
- 画面构成：画面里有什么，素材是什么身份（实拍、合成、文字、UI 等）；
- 画面处理：素材怎么叠、怎么动、怎么进怎么出。复杂片段拆细时，这列必须覆盖素材使用方式、空间层级与遮挡、进入→保持→退出、运动方式、效果与最终画面效果；
- 附加效果：模糊、闪白、颗粒、颜色、定格等额外处理；
- 声音与节拍：该段对应什么声音、落在什么节拍上；
- 与下一段的衔接：该段如何过渡到下一段（动作方向延续、遮挡切换、闪白等）；
- 把握程度：高 / 中 / 低，可附证据编号，例如“高（F0012、A003）”。

时间线从视频开始连续覆盖到结束，不留空档，不制造重叠。普通段保持易读粒度，复杂段拆成更短区间。

### 3.2 声音和画面的配合方式

先解释这条视频实际使用的配合方式，结合真实时间说明谁先发生、相差多久、带来什么观看作用：

- 声音和画面同时发生；
- 画面提前行动；
- 音乐出现后画面再释放；
- 持续的声音连接前后两个画面；
- 画面跟随歌词、情绪或声音质感，而不是机械卡点。

## 第四部分：如果重新做一条，应该学什么

依次写：

1. 最值得保留的观看体验；
2. 可以直接复用的方法，按重要程度排序；
3. 不应照搬的人物、素材、绝对时间点、坐标和效果参数；
4. 使用新素材重新创作的执行顺序（先定新视频的类型与成立机制，再准备同性质的素材与音乐，再按时间线方法编排，最后对照检查）；
5. 最终检查表。

可复用方法每条使用：

```text
名称
适合什么时候使用
具体怎么剪
能带来什么效果
参考时间
画面依据
声音依据
把握程度
```

方法名称直接描述动作，例如“相同方向连接”“先慢后快再停一下”“重拍负责冲击、尾音负责连接”。至少整理一套可以照着执行的连续剪法，不能只写“节奏感强”“转场自然”等空泛评价。

最终检查表至少检查：

| 检查项 | 判断 |
| :-- | :-- |
| 开头是否让观众快速知道要看什么 | 是 / 否 |
| 音乐增强时画面是否同步加强 | 是 / 否 |
| 快切是否服务明确的节奏变化 | 是 / 否 |
| 不同场景之间是否存在动作或声音连接 | 是 / 否 |
| 高潮前是否完成足够蓄力 | 是 / 否 |
| 高潮后是否留出缓冲 | 是 / 否 |
| 是否存在只炫技、没有观看作用的效果 | 是 / 否 |
| 新视频是否保留方法而不是照搬原片 | 是 / 否 |
