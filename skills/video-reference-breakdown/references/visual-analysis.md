# 画面分析方法

## 观察顺序

1. 先看全片联系表，找到主要段落和画面密度变化。
2. 按时间查看主要画面是否真实改变。
3. 在同一主要画面内查看字幕、遮挡、放大、移动、颜色和效果变化。
4. 将画面变化与同一时间的声音变化对照。
5. 对边界不清的片段补充高密度帧。

## 主要画面与画面内部变化

主要人物、主体或叙事承载内容发生改变时，可作为新的主要画面。以下情况通常只属于画面内部变化：

- 同一镜头内放大或缩小；
- 字幕出现、移动或退出；
- 画中画加入；
- 遮罩或前景物扫过；
- 亮度、颜色、模糊和透明度变化；
- 同一主体持续运动。

不要把每一次效果变化都误写成一次镜头切换。

## 时间线粒度

- 普通段落按读者可以理解的动作阶段划分。
- 快切段落按主要画面变化划分。
- 同一画面内存在重要效果组合时，在“画面里的变化”中说明。
- 时间线连续覆盖全片，不留空档，不制造重叠。

## 重点片段选择

优先详解：

- 视频反复使用的连接方法；
- 高潮前的蓄力过程；
- 音乐变化与画面变化明显对应的片段；
- 不同空间或素材被自然连接的片段；
- 普通观看容易忽略，但实际影响很大的字幕、遮罩或运动安排。

## 作用解释

“产生的作用”写观众实际能够感受到的结果，例如：

- 引导视线到人物；
- 隐藏背景切换；
- 增强动作力度；
- 留出理解时间；
- 制造等待；
- 在高潮前蓄力；
- 让前后场景显得连续。

不写“提升高级感”“增强感染力”“让画面更丰富”等缺少具体含义的套话。
