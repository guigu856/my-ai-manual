# 剪映双音色脚本配音与导出规范

## 目标

把对话中的文字脚本制作成一条连续的双音色 WAV 音频，并保留可回查的剪映工程。

## 固定规则

- 脚本已在当前对话中时，直接使用，不重复索要。
- 每次新建空白剪映工程；历史草稿、历史脚本、历史音频不作为本次输入。
- A 为提问，使用收藏音色“甜美少女”。
- B 为反驳和讲解，使用收藏音色“曼波讲故事”。以剪映界面实际显示名称为准。
- 转音频前先清洗脚本：自动去掉角色标签、标题、分镜标记、括号内非口播内容、语气/操作提示及其他说明性文字；只保留实际需要朗读的正文。无法确定是否需要朗读的内容，暂不删除，单独标记复核。
- 不改词、不改语序、不擅自改语速、音量或音色。
- 剪映文本朗读单段不超过 500 字；优先按段落和完整语义切分，禁止在短语中间硬切。
- 连续性以音频轨道为准，不以文本轨道为准。

## 标准流程

1. **读取脚本**：识别 A/B 角色，保留原文标点和段落意群。
2. **新建工程**：打开剪映，新建空白草稿。出现“当前草稿将自动保存”确认框时，先确认保存对象，再创建新草稿。
3. **拆分脚本**：
   - A：单独作为第一段提问。
   - B：包含“当然不对”和全部讲解内容；按语义拆成若干段，每段 ≤500 字。
4. **生成 A 音频**：添加文本（不是添加口播稿是点击添加文本栏中的默认文本） → 输入 A → 进入“朗读” → 收藏 → 选择“甜美少女” → 开始朗读 → 等待完成。
5. **生成 B 音频**：对每个 B 分段重复：
   - 将播放头定位到上一段音频末尾；
   - 添加新的文本片段并输入本段文字；
   - 选择“曼波讲故事”并开始朗读；
   - 等待“文本朗读完成”；
   - 再定位到新音频末尾，继续下一段。
6. **检查连续性**：查看音频轨道波形，确认片段首尾相接、无空白间隔、无重叠；允许语音内部存在自然停顿。
7. **导出**：打开导出，关闭视频导出，仅保留音频导出；格式选 WAV，文件名包含主题和“新建/最终”等状态标记。
8. **验证文件**：确认文件存在，再检查时长、编码、采样率、声道数和文件大小；最后报告绝对路径。

## 提速与准确性要点

- 每生成一段后立即等待完成，不连续点击，避免朗读任务叠加。
- 用 `End` 定位音频末尾，比按文本片段长度估算更可靠。
- 文本过长时先拆分，再逐段朗读；不要生成后再硬切音频。
- 新工程中只保留本次脚本和本次生成的音频，避免历史素材混入。
- 导出前只检查音频轨道；字幕或文本片段的连续性不能替代音频连续性检查。
- 未完成文件验证前，不报告“已导出完成”。

## 异常处理

- **打开的是历史工程**：停止操作，重新新建空白工程。
- **单段超过 500 字**：回到语义边界重新切分，不直接提交朗读。
- **出现音频间隙或重叠**：停止导出，回到上一段末尾重新接续或重生成。
- **导出名称或路径不清楚**：先设定清晰名称，再导出；交付时给出绝对路径。
- **旧导出与本次脚本不一致**：标记为历史文件，不作为交付结果。

## 交付检查清单

- [ ] 使用了当前对话中的脚本
- [ ] 使用了新建空白工程
- [ ] A/B 音色选择正确
- [ ] B 每段 ≤500 字且按语义切分
- [ ] 音频轨道首尾连续
- [ ] 已导出 WAV
- [ ] 已核验文件存在、时长和媒体参数
- [ ] 已报告绝对路径
